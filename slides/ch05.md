# 5.1 决策树是怎样做决定的

## 决策树的结构
!mermaid 1
- **根节点**：第一个问题
- **内部节点**：中间的问题
- **分支**：问题的一种回答
- **叶节点**：给出结论
- 每条路径 = 一条“如果……那么……”规则

::: notes
可以先玩一轮“二十个问题”：老师心里想一样东西，学生只能问是不是。会玩的人先问能砍掉一半可能性的问题，这就是决策树挑特征的思路。树的深度：从根到叶最长路径上的问题数，这棵树深度是 2。
:::

## 决策树怎样“学”出来
- **挑问题**：选最能分开类别的特征
- **分数据**：按回答把样本分给子节点
- **重复**：对每个子节点重复，直到停止
- 停止：节点已纯 / 没有特征 / 到达深度上限
- 每步只挑眼前最好的，叫**贪心策略**

::: notes
关键是第一步：用什么标准判断“最能分开类别”。下一节讲三种标准。
:::

# 5.2 信息熵、信息增益与基尼系数

## 纯度与信息熵
- 一筐全是红球：**最纯**，熵 = 0
- 红蓝各半：**最乱**，熵 = 1
- 熵越小，节点越纯
- 公式：H(D) = −Σ pₖ log₂ pₖ
- 约定 0 × log₂0 = 0

::: notes
先用两个篮子直观比较，再给公式。板书：甲篮子 p=1，H=0；乙篮子 p=0.5，H = −(0.5×(−1)+0.5×(−1)) = 1。提醒学生计算器上 log₂x = ln x ÷ ln 2。
:::

## 信息增益与 ID3
- 信息增益 = 问之前的熵 − 问之后的**加权**熵
- 增益越大，问题问得越好
- **ID3**（昆兰，1986）：每次选增益最大的特征
- 例：15 条贷款记录，批准 9、不批准 6
- H(D) = 0.971

::: notes
带学生看网页上的 15 行数据表。强调“加权”：分组后的熵要按每组样本数占比加权平均，这是计算题最容易错的地方。
:::

## 算一算：哪个特征当根节点
| 特征 | 分组（批准 / 不批准） | 加权熵 | 信息增益 |
|---|---|---|---|
| 年龄 | 青 2/3，中 3/2，老 4/1 | 0.888 | 0.083 |
| 有工作 | 是 5/0，否 4/6 | 0.647 | 0.324 |
| 有自己的房子 | 是 6/0，否 3/6 | 0.551 | **0.420** |
| 信贷情况 | 一般 1/4，好 4/2，非常好 4/0 | 0.608 | 0.363 |

::: notes
板书“有自己的房子”这一行：有房 6 人全批，熵 0；没房 9 人批 3 不批 6，熵 0.918；加权 9/15 × 0.918 = 0.551；增益 0.971 − 0.551 = 0.420。其余三行让学生分组算一个，对照表格。没房的 9 人再挑，“有工作”增益最大，于是得到师傅的口诀。
:::

## 动手试：决策树生长
!sim decision-tree-split
- 在根节点换不同特征
- 观察信息增益和基尼系数
- 先选“年龄”，树要长多深？

::: notes
课堂演示 3–5 分钟，学生可以扫码在手机上操作。让学生体会：先问好问题，树又浅又准；先问差问题，树要长很深。
:::

## 信息增益率与 C4.5
- 信息增益**偏爱取值多**的特征
- 例：“编号”有 15 个值，增益 0.971 最大，却毫无用处
- **C4.5**（昆兰，1993）：增益 ÷ 固有值
- 编号 0.971 ÷ 3.907 ≈ 0.249
- 有房 0.420 ÷ 0.971 ≈ 0.433，重新排第一

::: notes
C4.5 实际是两步：先挑增益高于平均的特征，再在其中选增益率最高的。C4.5 还能处理连续特征和缺失值，带剪枝，曾被评为数据挖掘十大算法之首。
:::

## 基尼系数与 CART
- 基尼系数：随机抽两个样本、**类别不同**的概率
- Gini = 1 − Σ pₖ²，不用算对数
- 贷款数据：0.48 → 按房子分后 0.267
- **CART**（布雷曼等，1984）只生成**二叉树**
- 连续特征：试“月收入 ≤ 门槛”，取相邻值中点
- scikit-learn 用的就是 CART

::: notes
例：月收入有 4000、6000、9000，候选门槛 5000 和 7500。scikit-learn 的类别特征要先编码成数值。
:::

## 三种算法对比
| 算法 | 依据 | 树形 | 任务 | 特点 |
|---|---|---|---|---|
| ID3 | 信息增益 | 多叉 | 分类 | 只能离散特征，无剪枝 |
| C4.5 | 信息增益率 | 多叉 | 分类 | 连续特征、缺失值、剪枝 |
| CART | 基尼系数 / 均方误差 | 二叉 | 分类和回归 | sklearn 采用，集成的基础 |

::: notes
证书考点：人工智能数据处理工程师（高级）数据挖掘模块，常考三种算法的指标、给小表算根节点、criterion 参数取 gini 或 entropy。
:::

# 5.3 回归树、过拟合与剪枝

## 回归树
- 叶节点给出一个**数值**：落进来样本的平均值
- 划分标准：让**均方误差**下降最多
- 例：4 套房子按面积分组，各组取均价
- 预测结果是“台阶状”的，不是一条平滑曲线

::: notes
讲网页 5.3.1 的 4 套房例子。台阶状预测是后面梯度提升树“多棵树叠加”能逼近曲线的原因。
:::

## 决策树为什么容易过拟合
![深度与准确率](img/lab5_1_depth.png)
- 不限深度：每个叶子只剩一两个样本
- 相当于**背答案**
- 训练集 100%，测试集明显下降
- 深度 6 最好：测试 0.827；不限深度 0.773

::: notes
这张图来自实验 5-1 的真实运行结果，2000 条模拟贷款数据。训练准确率一直升，测试准确率先升后降。
:::

## 剪枝：给树“修枝”
- **预剪枝**：边长边限制
  - `max_depth`、`min_samples_leaf`、`min_samples_split`
- **后剪枝**：先长满再剪
  - `ccp_alpha`（代价复杂度剪枝）
- 参数怎么取：在**验证集**或交叉验证上比较

::: notes
预剪枝快但可能剪早了；后剪枝效果通常更好但慢。不能用测试集挑参数，第 9 章会系统讲。
:::

## 决策树的优点和缺点
- 优点：规则**看得懂**，能直接给业务和监管看
- 优点：不用标准化，能混合数值和类别特征
- 缺点：容易过拟合
- 缺点：**不稳定**，数据小变动树就大变
- 解决办法：很多棵树一起用，这就是集成学习

::: notes
判断题常考：决策树不需要标准化。
:::

# 5.4 集成学习：三个臭皮匠

## 为什么“集体”比个人强
- 3 个各 70% 准、互相独立的人投票
- 至少 2 人对的概率：**78.4%**
- 25 个人投票：超过 **98%**
- 前提：每个成员比瞎猜强，而且**彼此不同**

::: notes
板书：0.7³ + 3 × 0.7² × 0.3 = 0.343 + 0.441 = 0.784。强调“彼此不同”：如果 3 个人一模一样，投票等于一个人。
:::

## 两条路线：Bagging 和 Boosting
!mermaid 2

::: notes
Bagging：并行训练，平均投票，主要降低方差；Boosting：串行训练，后一个纠正前一个，主要降低偏差。
投票法：硬投票看票数，软投票平均概率。Stacking：用一个新模型学“怎样综合各成员的意见”。
:::

# 5.5 随机森林

## 两种随机
- **样本随机**：每棵树有放回地抽样（自助采样）
- 约 **63.2%** 被抽中，**36.8%** 没被抽中
- **特征随机**：每次划分只看一部分特征
- 分类常用 √特征数
- 最后多数投票（回归取平均）

::: notes
36.8% 来自 (1 − 1/n)ⁿ → 1/e。这是单选第 7 题。
:::

## 袋外误差与特征重要性
![特征重要性](img/lab5_2_importance.png)
- 没抽中的样本当“自带测试集”：**袋外准确率**
- 特征重要性：这个特征让不纯度下降了多少
- 实验 5-2：OOB 0.798，测试 AUC 0.819

::: notes
提醒：特征重要性说明“模型用得多”，不等于因果关系；高基数特征会被高估。图来自实验 5-2 的客户流失数据。
:::

## 主要参数
| 参数 | 含义 | 常用取值 |
|---|---|---|
| `n_estimators` | 树的数量 | 100–500，越多越稳，不会过拟合 |
| `max_features` | 每次划分看几个特征 | `"sqrt"` |
| `max_depth` | 每棵树的最大深度 | 不限或 10–20 |
| `min_samples_leaf` | 叶子最少样本数 | 1–5 |
| `oob_score` | 是否计算袋外得分 | `True` |

::: notes
判断题：树越多越容易过拟合，错。树多了只是慢，效果趋于稳定。
:::

# 5.6 Boosting：一棵树纠正上一棵的错

## AdaBoost：给做错的题加分量
- 每轮训练一个弱分类器
- 做错的样本**权重调高**，下轮重点学
- 分类器权重 α = ½ ln((1 − e) / e)
- 错误率 e 越低，说话分量越大

::: notes
类比：错题本。e = 0.5 时 α = 0，等于瞎猜的分类器不给发言权。
:::

## 梯度提升树：拟合残差
| 房子 | 真实价 | 第 0 轮预测 | 残差 | 第 1 轮后（学习率 0.5） |
|---|---|---|---|---|
| A | 100 | 140 | −40 | 120 |
| B | 120 | 140 | −20 | 130 |
| C | 200 | 140 | +60 | 170 |
| 误差平方和 | | 5600 | | 1550 |

::: notes
第 0 轮用平均值 140 预测。下一棵树拟合的目标是残差 −40、−20、+60（单选第 9 题）。假设这棵树完美拟合残差，乘学习率 0.5 再加上去。误差平方和从 5600 降到 1550。
:::

## 学习率与早停
!sim bagging-boosting
- 学习率小：每步走得稳，需要**更多树**
- 学习率大：几轮就到，容易过拟合
- **早停**：验证集不再变好就停

::: notes
动画里对比学习率 1.0 和 0.1，看训练误差和测试误差曲线。实验 5-3：XGBoost 默认参数训练 AUC 1.000、测试 0.801；加早停后测试 0.836。
:::

## XGBoost 和 LightGBM
- **XGBoost**（陈天奇，2016）：正则化、二阶导数、并行
- **LightGBM**（微软亚洲研究院，2017）：直方图、按叶生长，更快
- CatBoost：类别特征处理好
- 表格数据竞赛和工业界的主力

::: notes
证书考点：Python 技术应用工程师（高级）集成学习模块，要求会用随机森林、XGBoost、LightGBM 建模和调参。注意 LightGBM 的 num_leaves 与 XGBoost 的 max_depth 对应关系。
:::

## 实验 5-3 的结果
| 模型 | 测试 AUC |
|---|---|
| 逻辑回归 | 0.836 |
| 随机森林 | 0.819 |
| XGBoost（早停） | 0.836 |
| LightGBM（早停） | 0.837 |

- 复杂模型**不一定赢**：先建一个简单基线

::: notes
如实讲：这份模拟流失数据大部分关系是线性的，逻辑回归就够好。选模型要看验证集，也要看可解释性和部署成本。5.7 前沿视窗放在课后线上阅读。
:::
