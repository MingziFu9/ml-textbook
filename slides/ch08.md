# 8.1 聚类与 K 均值

## 聚类 ≠ 分类
| | 分类 | 聚类 |
|---|---|---|
| 训练数据 | 有标签 | **没有标签** |
| 类别 | 事先定好 | 算法分出来 |
| 结果含义 | 现成的 | 要人来**起名** |
| 评价 | 准确率 | 紧不紧、开不开、**有没有用** |

::: notes
聚类最常见的用途是客户分群，也常作为探索数据的第一步。
:::

## K 均值：四步
- ① 随机选 K 个**簇中心**
- ② 每个样本分到最近的中心
- ③ 中心移到本组的平均位置
- ④ 重复 ②③，直到分组不变
- 用之前要**标准化**

::: notes
目标是让簇内平方和最小，两步都只会让它变小或不变，所以一定会停。但可能停在较差的结果：sklearn 用 k-means++ 选初始中心，并设 n_init=10 跑十次取最好。
:::

## 算一算：迭代两轮
| 轮次 | 分组 | 新中心 |
|---|---|---|
| 初始 | 中心 A(1,1)、B(2,1) | |
| 第 1 轮 | {A, C}、{B, D, E, F} | (1, 1.5)、(5.25, 4.25) |
| 第 2 轮 | {A, B, C}、{D, E, F} | (1.33, 1.33)、(6.33, 5.33) |
| 第 3 轮 | 不再变化 | 收敛 |

::: notes
6 个点：A(1,1)、B(2,1)、C(1,2)、D(6,5)、E(7,5)、F(6,6)。第 2 轮 B 到 (1,1.5) 距离 1.12，到 (5.25,4.25) 距离 4.60，改到第 1 组。簇内平方和 30.0 → 2.67。初始中心很差，几轮也能纠正过来。
:::

## 选 K：肘部法则与轮廓系数
![肘部法则与轮廓系数](img/lab8_1_k.png)
- 肘部：下降由快变慢的拐点
- 轮廓系数 s = (b − a) / max(a, b)，越接近 1 越好
- 实验 8-1：两种方法都指向 **K = 4**（0.433）

::: notes
a 是到本簇其他样本的平均距离，b 是到最近另一簇的平均距离。手算：A 的 a = 1，b ≈ 6.90，s ≈ 0.855；6 个点平均 0.823。簇内平方和随 K 一直下降，不能选最小的。真实数据还要看业务：运营能做几套方案、每群能否说清楚。
:::

## K 均值的局限
- 要事先给 K，对初始中心敏感
- 只能分**圆团状**的簇：月牙形 ARI 只有 **0.479**
- 倾向于把各簇分得一样大
- 受异常值影响
- 每个点都必须归入某个簇

::: notes
调整兰德指数 ARI：1 与真实分组完全一致，0 相当于随机乱分。后几条局限，层次聚类和 DBSCAN 可以部分解决。
:::

# 8.2 层次聚类与 DBSCAN

## 层次聚类与树状图
![树状图](img/lab8_2_dendrogram.png)
- 每个样本自成一簇，每次合并最近的两簇
- 横切一刀：切到几根竖线就是几簇
- 不必事先定 K；样本多时慢

::: notes
链接方式：Ward（默认，簇圆、均衡）、单链接（最近两点，能顺着弯曲形状连下去）、全链接、平均链接。月牙形用单链接 ARI 1.000。
:::

## DBSCAN：按密度找簇
- 参数：半径 **eps**、最少点数 **min_samples**
- **核心点**：圆内（含自己）≥ min_samples 个点
- **边界点**：不是核心点，但在核心点圆内
- **噪声点**：其余，编号 −1
- 核心点一路**密度可达**，连成一个簇

::: notes
优点：不用给簇数，能找任意形状的簇，自动识别噪声。缺点：eps 不好定，同一个 eps 难以适合疏密不同的簇。
:::

## 算一算：一维 DBSCAN
- 数据 1、2、3、4、10、11、12、20；eps = 1.5，min_samples = 3
- 核心点：2、3、11
- 边界点：1、4、10、12
- 噪声点：**20**
- 结果：2 个簇，簇数是算法自己找的

::: notes
点 2 的圆内有 1、2、3，三个点；点 1 的圆内只有 1、2，不是核心点，但在核心点 2 的圆内。
:::

## eps 的影响（月牙形）
| eps | 簇数 | 噪声点 | ARI |
|---|---|---|---|
| 0.1 | 21 | 160 | 0.036 |
| 0.2 | 3 | 5 | 0.799 |
| 0.3 | 2 | 0 | **1.000** |
| 1.0 | 1 | 0 | 0.000 |

::: notes
eps 太小，簇碎、噪声多；太大，连成一片。先标准化，min_samples 取特征数的两倍左右，再从小到大试 eps。
:::

## 动手试：DBSCAN
!sim dbscan-density
- 月牙形：eps 从 0.1 拖到 1.0
- eps = 0.2，min_samples 5 → 10
- 点一个点，看它的邻域

::: notes
页面结果与 sklearn 一致：月牙形 eps 0.2、min_samples 10 时 8 簇、70 个噪声点。
:::

- 球形：都行（0.990）

# 8.3 降维与主成分分析

## 为什么要降维
- **看图**：64 维画不出来
- **去冗余**：次数和金额说的几乎是同一件事
- **缓解维度灾难**（第 7 章）
- **加快计算**
- 降维 = 构造新特征；特征选择 = 挑原特征

::: notes
降维和特征选择的区别是常考点。
:::

## PCA：找最能拉开差距的方向
- 所有点投影到一条直线上
- 投影后**方差最大** = 第一主成分
- 等价于：垂直距离平方和最小
- 主成分 = 原特征的**线性组合**
- 先标准化（像素等同单位除外）

::: notes
例子：第一主成分 ≈ 0.43 × ln(1+次数) + 0.90 × ln(1+金额)（先减去均值），相当于“购买力”分数。
:::

## 动手试：PCA 投影方向
!sim pca-projection
- 0°：只保留 **19.7%**
- 45°：87.9%
- 64.3°：**98.5%**（第一主成分）

::: notes
转到约 154°（与第一主成分垂直）只剩 1.5%，就是第二主成分。保留 + 丢掉 = 100%，转到哪儿都不变。
:::

## 方差解释率：留几个
- 手写数字 64 维：前 2 个只有 **28.5%**
- 90% 要 21 个，95% 要 29 个
- `PCA(n_components=0.95)` 自动选
- 降到 20 维，SVM 仍是 **0.989**

::: notes
2 个 0.639，5 个 0.922，10 个 0.978，20 个起与不降维相同。数据小，看不出提速。PCA 只在训练集上拟合，放进流水线。
:::

## 主成分长什么样
![主成分与还原](img/lab8_3_components.png)
- 每个主成分是一种“笔画模式”
- 2 个还原：模糊（误差 1.89）
- 40 个还原：几乎一样（误差 0.20）

::: notes
图片 ≈ 平均图片 + 若干主成分的加权和，记住几个权重就能大致还原，这是 PCA 能压缩数据的原因。
:::

## t-SNE：只用来看图
![PCA 与 t-SNE](img/lab8_3_pca_tsne.png)
- 保留**邻居关系**：近邻同类比例 PCA 0.571 → t-SNE **0.982**
- 坐标、团间距离没有含义；结果随参数变
- 没有 `transform`，不能处理新样本；慢（7.0 秒）

::: notes
建模用 PCA，看图用 t-SNE；数据大时先 PCA 到 50 维再 t-SNE。UMAP 更快，也常用。
:::

# 8.4 异常检测

## 三类方法
| 方法 | 思路 | 局限 |
|---|---|---|
| 3σ、箱线图 | 单个特征超出范围 | 一次只看一个特征 |
| 基于聚类 | DBSCAN 噪声点、离簇中心远 | 依赖聚类效果 |
| **孤立森林** | 越容易被孤立越异常 | 找不到伪装得像正常的 |

::: notes
很多欺诈是“金额略高 + 凌晨 + 境外 + 新设备”，每项单独看不算异常，合在一起才可疑。
:::

## 孤立森林
- 随机选特征、随机位置切一刀，反复切
- 异常点远离人群，**几刀就被孤立**
- 几百棵随机树，看平均路径长度
- **路径越短，越异常**；不需要标签
- `contamination`：预计的异常比例

::: notes
例：金额 10、12、13、15、100 元，在 10～100 之间随机切一刀，约 94% 的可能一刀就把 100 切出来。Liu、Ting 和周志华 2008 年提出。
:::

## 找可疑交易（实验 8-2）
| 方法 | 标出 | 真欺诈 | 命中率 |
|---|---|---|---|
| 随机抽查 | 200 | 约 2 | 约 1% |
| 金额 3σ | 45 | 11 | 24.4% |
| 孤立森林 | 200 | 54 | **27.0%** |
| 分数最高 50 笔 | 50 | 24 | **48.0%** |

::: notes
训练完全不用标签。不寻常不一定是欺诈（可能出国旅游），结果交给人工复核，或作为特征加入有监督模型。无监督的价值在于发现没被标注过的新型异常。
:::

| 客户群 | 人数占比 | 消费额占比 | 建议 |
|---|---|---|---|
| 高价值忠实 | 14.4% | **52.7%** | 专属权益，不发大额券 |
