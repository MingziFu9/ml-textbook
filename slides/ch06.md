# 6.1 最大间隔分类器

## 能分开两类的直线有无数条
- 两类样本 = 路两边的房子
- 能分开两类的路有无数条
- 窄路：新样本稍偏一点就分错
- **宽路**：离两边都远，容忍度大
- SVM：选路**最宽**的那条

::: notes
线性可分：存在一条直线能把两类完全分开。所有能分开的直线训练误差都是 0，要靠“路宽”来区分好坏。
:::

## 间隔与支持向量
!mermaid 1
- 路边线：f(x) = ±1
- 间隔宽度 = **2 / ‖w‖**
- 压在路边线上的点 = **支持向量**
- 边界只由支持向量决定

::: notes
远处的样本删掉、挪动，边界都不变，这就是名字的由来。求解结果中只有支持向量的系数不为 0。SVM 的优化问题有唯一最优解，sklearn 底层用 LIBSVM 的 SMO 算法。
:::

## 算一算：3 个点的 SVM
| 点 | 类别 | f = 0.5x₁ + 0.5x₂ − 2 | 支持向量？ |
|---|---|---|---|
| A(3, 3) | 正 | 1 | 是 |
| B(4, 3) | 正 | 1.5 | 否 |
| C(1, 1) | 负 | −1 | 是 |

::: notes
例子取自李航《统计学习方法》例 7.1。间隔 = 2 / √(0.5² + 0.5²) ≈ 2.83，正好是 A、C 两点的距离。把 B 挪到 (5, 4) 或删掉，边界不变。请学生带计算器验证。
:::

# 6.2 软间隔与惩罚参数 C

## 软间隔与合页损失
- 现实数据有重叠、有录错的点
- **软间隔**：允许越界，但要付代价
- 合页损失 = max(0, 1 − y·f(x))
- 正类 f = 1.8 → **0**；f = 0.4 → **0.6**；f = −0.5 → **1.5**
- 路外的点不计较，只盯着路边的点

::: notes
对比交叉熵：交叉熵对每个样本都有一点损失，合页损失对分得足够好的样本不再计较，所以 SVM 只由支持向量决定。
:::

## C 的作用（实验 6-1）
![C 对间隔的影响](img/lab6_1_C.png)
- C = 0.01 → 100：间隔 4.04 → **0.68**
- 支持向量 44 → 6 个
- C 大：越界代价高，路窄，易过拟合

::: notes
四种 C 训练集都只分错 2 个点，看不出区别，要靠新数据（交叉验证）来选。注意方向：C 越小正则化越强，和岭回归的 alpha 相反、和逻辑回归的 C 相同。
:::

## 一个异常点的影响
![异常点](img/lab6_1_outlier.png)
- 无异常点：间隔 1.58
- C = 1000：为了一个点，间隔压到 **0.40**
- C = 0.1：放弃它，间隔 **2.91**

::: notes
提问：如果这个点是录入错误，哪个模型更可信？业务数据里有录错、有特殊客户时，C 不宜太大。
:::

# 6.3 核技巧

## 抬到高维再切一刀
!mermaid 2
- 同心圆：线性核只有 **0.489**
- 加特征 r² = x₁² + x₂²
- 内圈 r² 平均 0.27，外圈 1.01
- 线性核 → **1.000**

::: notes
三维中的水平面 r² ≈ 0.59，投影回二维就是一个圆。低维中弯曲的边界，在合适的高维空间中可能是平直的。
:::

## 核函数：不用真的抬上去
- 求解只用到样本之间的**点积**
- x = (1, 2)，z = (3, 1)
- 抬上去：φ(x)·φ(z) = 9 + 12 + 4 = **25**
- 直接算：(x·z)² = 5² = **25**
- 核函数 = 两个样本的**相似程度**

::: notes
φ(x) = (x₁², √2·x₁x₂, x₂²)。高维甚至无穷维时，核函数仍只在原始空间里算。预测时 f(x) = Σ αᵢyᵢK(xᵢ, x) + b，新样本和哪类的支持向量更像就判为哪类。
:::

## 三种常用核函数
![三种核函数](img/lab6_2_kernels.png)
- 线性核：特征多（文本）时先试
- 多项式核：较少用，`coef0` 默认 0
- **RBF 核**：拿不准时首选，`SVC` 默认

::: notes
月牙形：0.856、0.856、0.900；同心圆：0.489、0.678、1.000。3 次多项式核 coef0=0 只含三次项，画不出圆；改成 2 次、coef0=1 就能到 1.000（实操题 1）。
:::

## gamma：每个点的影响范围
| 距离 d | γ = 1 | γ = 10 |
|---|---|---|
| 0.5 | 0.779 | 0.082 |
| 1 | 0.368 | 0.00005 |
| 2 | 0.018 | ≈ 0 |

::: notes
RBF 核 = e^(−γd²)。gamma 大，影响范围小，边界绕圈，易过拟合；gamma 小，边界平滑，可能欠拟合。默认 gamma = "scale" = 1 /（特征数 × 方差），标准化后的二维数据是 0.5。
:::

## C 与 gamma 一起调
![gamma 的影响](img/lab6_2_gamma.png)
- 左上角（都小）：欠拟合，约 0.87
- gamma = 100：训练 1.000，交叉验证 0.79～0.91
- 并列最好：选支持向量最少的
- C = 10、gamma = 1：测试 **0.967**

::: notes
交叉验证并列 0.948 的有三组：C = 0.1、gamma = 10 有 210 个支持向量（所有训练样本），测试最低 0.922。调参方法：C、gamma 按 10 倍递增取值，网格上交叉验证，第 9 章用 GridSearchCV 自动完成。
:::

# 6.4–6.5 SVR 与适用场景

## 支持向量回归
- 预测值上下留宽 **ε** 的管道
- 管道内的误差**不计**
- ε 5 → 40：支持向量 15 → 4，测试 MSE 624 → 1170
- 最好的 SVR 623.7，不如 2 阶多项式 **529.4**

::: notes
SVR 对小误差睁一只眼闭一只眼，大误差按距离不按平方，受异常值影响小。奶茶店的真实规律就是二次曲线，20 个样本时灵活的 RBF 核占不到便宜。没有在所有数据上都最好的模型。
:::

## 手写数字（实验 6-3）
| 模型 | 测试准确率 | 认错 |
|---|---|---|
| SVM（RBF 核） | **0.989** | 6 |
| SVM（标准化） | 0.983 | 9 |
| 逻辑回归 | 0.981 | 10 |
| 随机森林 | 0.969 | 17 |

::: notes
像素单位相同，不标准化反而更好：边缘像素几乎总是 0，标准化会放大偶然的笔画。每个数字只有 50 张训练时：SVM 0.985，逻辑回归 0.950，随机森林 0.954。10 类用一对一，共 45 个二分类器。
:::

![认错的 6 张](img/lab6_3_wrong.png)
- 两张“8”认成“1”：又窄又细
- 有的连人也难认
- 改进：更高分辨率、更多样本

## SVM 适合什么任务
| 适合 | 不适合 |
|---|---|
| 中小样本（几百到几万） | 超大数据（10 万条以上很慢） |
| 特征多：文本、基因 | 要解释“为什么” |
| 边界弯曲 | 需要概率输出（要额外设置） |

::: notes
数据大时用 LinearSVC 或梯度提升树；要解释时用逻辑回归或决策树。SVC(probability=True) 训练慢约 5 倍。
:::

## 前沿视窗
- 小样本：医院几百例、产线几百个不良品
- 文本分类：线性 SVM 至今仍是常用基线
- 生物信息：几十个样本、几万个基因
- 大模型嵌入 + 线性 SVM / 逻辑回归
- 神经正切核：宽神经网络 ≈ 核方法

::: notes
深度学习“喂不饱”的场合 SVM 往往更稳。先用预训练模型把文本、图片变成向量，再训练一个小分类器，是今天很常见的做法。
:::
