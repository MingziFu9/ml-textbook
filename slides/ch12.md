# 12.2 经典预测方法

## 先做基准
- 朴素：明天 = 今天
- 季节朴素：= 上周同一天
- 移动平均：最近 7 天 (2000 + 1950 + … + 2650) ÷ 7 ≈ **2264**
- 问题：星期效应被平均掉了

::: notes
复杂模型只有明显超过基准才值得用。移动平均也用来看趋势（7 日中心移动平均）。
:::

## 算一算：指数平滑
- 新预测 = α × 实际值 + (1 − α) × 原预测
- 销量 2000、2400、2200，α = 0.3：2000 → 2120 → **2144**
- α = 0.8：2000 → 2320 → **2224**
- 霍尔特：加趋势；霍尔特—温特斯：再加季节

::: notes
实验中简单指数平滑学到 α = 0.040，把星期起伏当噪声；霍尔特—温特斯 α = 0.518，β、γ 接近 0。
:::

## ARIMA 的直观理解
| 部分 | 含义 |
|---|---|
| AR，阶数 p | 今天和前 p 天有关 |
| I，阶数 d | 先差分 d 次 |
| MA，阶数 q | 用前 q 天的误差修正 |

- 有季节：SARIMA，s = 7
- 按 AIC 在训练集上选阶：(2,1,1)(0,1,1,7)

::: notes
ARIMA 里的 MA 不是移动平均法。选阶数只用训练集，看测试集挑就是泄露。
:::

## 算一算：MAE 与 MAPE
- 实际 2000、2500、3000；预测 2100、2400、2700
- MAE = (100 + 100 + 300) ÷ 3 ≈ **166.7 件**
- MAPE = (5% + 4% + 10%) ÷ 3 ≈ **6.33%**
- 实际值很小时 MAPE 失真；要和基准比

::: notes
冷门商品卖 1 件、预测 3 件，误差 200%。霍尔特—温特斯比季节朴素 MAE 少 42%。

## 探索与利用
- 饭馆：去吃过的好店（利用），还是试新店（探索）？
- ε-贪心：ε 的概率随机，1 − ε 选最好；ε 从 1 降到 0.01
- ε = 0，总选第一个：一次也没成功
- ε = 0，随机选：Q 表只有 7 个非零数（正常 35 个）

::: notes
不探索只认识碰巧找到的一条路，环境一变就不知所措。
:::

## 课堂练习

## 算一算：最短路线值多少分
- 最少 6 步，只有最后一步得 1 分，γ = 0.95
- 累计奖励 = 0.95⁵ ≈ **0.774**
- 多走 2 步：0.95⁷ ≈ 0.698
- 马尔可夫：下一步只看现在的状态和动作

::: notes
γ 接近 1 有远见，γ 小只顾眼前。折扣让智能体倾向走最短路线。
:::

# 12.6 Q 学习

## Q 表与更新规则
- Q(s, a) ← Q(s, a) + α [r + γ max Q(s′, ·) − Q(s, a)]
- α = 0.1，γ = 0.95：
- Q(14, 右) = 0 + 0.1 × (1 − 0) = **0.1**
- Q(13, 右) = 0.1 × (0.95 × 0.1) = **0.0095**

::: notes
目标值 = 奖励 + 新状态最好的分数打折。奖励一格格往回传，每格乘一次 γ。
:::

# 12.7 本领域的责任

## 算法公平性：分组看一看
| 群体 | 批准率 | 能还款者的召回率 |
|---|---|---|
| A | 60% | 0.80 |
| B | 40% | 0.50 |

- 批准率之比 0.67 < 0.8 → 查原因
- 删掉“性别”列不够：代理特征

::: notes
虚构示例。偏见来源：历史数据、样本不均衡、代理特征。公平有多种定义，关键是主动查、记录、说得出理由。
:::

## 可解释性与数据合规
- 《个人信息保护法》：自动化决策要透明、公平；个人有权要求说明
- 《数据安全法》：分类分级保护，合法正当收集
- 自查：来源、最小必要、去标识化、安全保管、公平与解释、记录留档

::: notes
算法推荐规定：提供关闭个性化推荐的选项，不得“大数据杀熟”。伦理总框架见“人工智能导论”第 9 章。
:::
