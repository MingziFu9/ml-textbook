# 2.1 数据质量与探索性数据分析

## 五类数据质量问题
| 问题 | 二手房数据中的例子（实验 2-1） |
|---|---|
| 缺失 | 建成年份缺 213 条，装修缺 88 条 |
| 重复 | 60 套房被重复抓取 |
| 格式不一致 | 304 条面积带“㎡”或“平米” |
| 单位不一致 | 5 套总价按“元”录入 |
| 异常 | 6 套面积多打了一个 0 |

::: notes
垃圾进，垃圾出。我国国家标准 GB/T 36344—2018 从规范性、完整性、准确性、一致性、时效性、可访问性六方面评价数据质量。
:::

## 描述性统计
- 集中趋势：均值、中位数、众数
- 离散程度：标准差、四分位数 Q1、Q3
- 总价均值 **5216.2** 万元，中位数 **243.0** 万元
- 均值远大于中位数 → 有极端大的值
- pandas：`describe()` 一行搞定

::: notes
问学生：用哪个数代表“典型房价”？中位数，因为它不受极端值影响。5 条按元录入的总价把均值拉高了 20 多倍。
:::

## 数据透视：各区单价中位数
| 区域 | 毛坯 | 简装 | 精装 |
|---|---|---|---|
| 天河 | 47100 | 50100 | 53400 |
| 海珠 | 33100 | 36300 | 39000 |
| 番禺 | 20800 | 23600 | 24700 |
| 增城 | 12000 | 13300 | 14400 |

::: notes
一张表看清两个规律：区域之间单价差三四倍，是最主要的因素；同一区内精装比毛坯贵 10%～20%。代码：pd.pivot_table(df, index="区域", columns="装修", values="单价_元每平方米", aggfunc="median")。证书常考 index 和 columns 写反、aggfunc 默认求平均。
:::

## 相关系数与辛普森悖论
- 取值 −1 到 1，衡量**线性**关系
- 单价—总价 0.77，面积—总价 0.39
- 怪事：建成年份—单价 **−0.26**，越新越便宜？
- 分区计算：每个区内都是 **0.25～0.38** 正相关
- 原因：新房多在远郊，区域才是关键
- **相关不等于因果**

::: notes
这是辛普森悖论：合并数据和分组数据结论相反。启示：建模时要把区域放进模型。相关系数接近 0 不代表没有关系，可能是 U 形等非线性关系。
:::

# 2.2 数据清洗

## 缺失值的处理
| 方法 | 适用情况 |
|---|---|
| 删除 | 缺失很少、随机缺失 |
| 统计量填充 | 有极端值用中位数 |
| 分组填充 | 与某个类别关系密切 |
| 单独一类“未知” | 缺失可能有含义 |
| 加缺失标记 | 让模型自己判断 |

::: notes
算一算：海珠区一套房没填建成年份，用全部数据的中位数 2007 年填，忽略了海珠是老城区；用海珠区的中位数 2004 年更合理。所有统计量只从训练集计算。
:::

## 异常值：找出可疑，再做判断
- **3σ 法则**：均值 ± 3 倍标准差之外
- **IQR 法**：Q1 − 1.5 × IQR 到 Q3 + 1.5 × IQR 之外
- 清洗后总价按 IQR 找出 **106** 套，其中 **74** 套在天河
- 它们是真实的大户型、好地段，**不能删**
- 能校验的用业务规则：单价 × 面积 ≈ 总价

::: notes
异常值规则只能“找出可疑”，不能代替判断。删掉真实的高价房，模型就不会给这类房子估价了。判断依据要写进清洗规范。
:::

## 数据清洗规范（节选）
| 编号 | 字段 | 规则 | 影响条数 |
|---|---|---|---|
| R1 | 全部 | 按房源编号去重 | 60 |
| R2 | 面积 | 去掉单位，转为数值 | 304 |
| R3 | 总价 | 单价校验后除以 10000 | 5 |
| R7 | 单价 | 删除（数据泄露） | 全部 |
| R8 | 建成年份 | 划分后按训练集同区中位数填 | — |

::: notes
完整规范有 10 条，每条写清字段、问题、规则、理由、影响条数。代码要与规范一一对应，执行后输出每条规则影响多少行。对应训练师三级“制定数据清洗规范，维护训练集和测试集”。
:::

# 2.3 特征编码与特征缩放

## 类别型特征的编码
- **标签编码**：0、1、2……只适合**有顺序**的类别
  - 楼层位置：低 0、中 1、高 2
- **独热编码**：每个取值一列 0/1，适合**无顺序**的类别
  - 区域、装修、朝向
- 取值很多（337 个小区）：合并稀有类、频数编码、**目标编码**
- 训练集、测试集编码后的列要**对齐**

::: notes
对区域用标签编码，模型会以为“海珠 = 2 × 越秀”，没有道理。目标编码要做平滑，而且只能用训练集计算，否则就是数据泄露。
:::

## 标准化与归一化
- **标准化**：z = (x − 均值) / 标准差
- **归一化**：x' = (x − 最小值) / (最大值 − 最小值)
- 算一算：面积均值 92.24、标准差 30.54
- 63.5 平方米 → z = (63.5 − 92.24) / 30.54 ≈ **−0.94**
- 需要缩放：K 近邻、SVM、K-Means、梯度下降类
- 不需要：决策树、随机森林、XGBoost

::: notes
标准化更常用；归一化适合像素这类有固定上下限的数据。树模型每次只比较一个特征的大小，单位不影响结果。拿不准时缩放一下一般没坏处。
:::

# 2.4 特征构造与特征选择

## 特征构造
- **日期特征**：挂牌月份、星期几、房龄
- **比率特征**：每室面积、负债率
- **交叉特征**：区域参考单价 × 面积
- **分箱**：把年龄分成青年、中年、老年
- 好特征来自对**业务的理解**

::: notes
线性回归只能加权相加，表达不了“总价 ≈ 单价 × 面积”。加入交叉特征“参考总价”后，线性回归 R² 从 0.836 提高到 0.903（实验 2-3）。
:::

## 特征选择的三类方法
| 方法 | 思路 | 例子 |
|---|---|---|
| 过滤法 | 按统计指标打分排序 | 相关系数、方差 |
| 包裹法 | 用模型效果反复试 | 递归特征消除 RFE |
| 嵌入法 | 训练时顺便选出 | Lasso、树的特征重要性 |

::: notes
实验 2-3 从 33 个特征中各选 10 个：过滤法 R² 0.886，包裹法和嵌入法都是 0.901，几乎达到全部特征的效果。特征越多不一定越好。
:::

# 2.5 数据集划分与数据泄露

## 先划分，再预处理
!mermaid 1
- 去重、改格式、修正错误：可以在划分前做
- 填充值、标准化参数、目标编码：**只用训练集算**
- 训练集 `fit`，测试集只 `transform`

::: notes
设想模型已经上线，来了一套新房，我们只能用历史数据算出的均值去标准化它。在划分前用全部数据算统计量，测试集的信息就混进了训练过程。
:::

## 三类常见的数据泄露
- **特征含有标签信息**：用单价预测总价
- **用到未来的信息**：用下月消费预测本月流失
- **预处理用了测试集**：划分前算均值、做目标编码
- 实验 2-3：加入单价，随机森林 R² 从 0.889 升到 **0.997**

::: notes
用户估价时不会告诉你单价，单价是总价除以面积算出来的。R² 0.997 几乎没有误差，现实中不可能，这就是信号。
:::

## 怎样发现数据泄露
- 成绩**好得难以置信**
- 某个特征的重要性**压倒一切**（单价占 0.607）
- **测试成绩比训练还好**（0.960 > 0.959）
- 上线后效果**骤降**
- 追问：预测那一刻，这个值能拿到吗？

::: notes
对每个可疑特征问两个问题：预测时刻能不能拿到？它是怎样算出来的？
:::
