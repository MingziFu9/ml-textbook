# 7.1 K 近邻

## 近朱者赤：找最像的邻居
- 新样本 → 找训练集中最近的 **K 个**邻居
- 分类：邻居投票；回归：取平均
- **没有训练过程**：只是把数据存起来
- 葡萄酒第 1 瓶：5 个邻居全是品种 0 → 判品种 0

::: notes
“懒惰学习”：训练不花时间，预测时要和所有训练样本比一遍，数据大时慢。葡萄酒数据：178 瓶、13 项化学成分、3 个品种。
:::

## 距离度量
| 距离 | A(0,0) 与 B(3,4) | 适合 |
|---|---|---|
| 欧氏距离 | √(9 + 16) = **5** | 一般数值数据（默认） |
| 曼哈顿距离 | 3 + 4 = **7** | 网格、城市街区 |
| 余弦相似度 | 只看方向 | 文本、嵌入向量 |

::: notes
C(1, 2) 和 D(2, 4)：欧氏距离 2.24，余弦相似度 1。两篇文章用词比例相同、长短不同，余弦相似度认为它们最像。葡萄酒数据上三种距离交叉验证 0.968、0.967、0.959，差别不大。
:::

## K 值的选择
![K 值曲线](img/lab7_1_k.png)
- K = 1：训练 1.000，边界支离破碎 → 过拟合
- K 很大：少数类被淹没 → 欠拟合
- 交叉验证选 K：K = 12，测试 0.963

::: notes
数据少时曲线会上下跳动（每一折只有二十几条），在一段平稳区间里选即可，不必死抠。二分类时 K 取奇数避免平票。
:::

## 动手试：KNN 决策区域
!sim knn-regions
- 先选“K = 5，不标准化”：为什么变成竖带？
- 再把 K 从 1 拖到 30
- 在交界处点一下，看投票

::: notes
不标准化：脯氨酸 278～1680，类黄酮 0.3～5.1，距离几乎只看横轴。动画中 K = 5 不标准化测试 0.667，标准化 0.963。
:::

## 必须标准化
- 脯氨酸标准差 308，非类黄酮酚 0.12
- 不标准化：距离平方中脯氨酸占 **70%**
- K = 5：不标准化 **0.722**，标准化 **0.944**
- 用训练集的均值、标准差变换测试集

::: notes
和 SVM 一样，凡是用距离的模型都要标准化：KNN、SVM、K-Means（第 8 章）。树模型不需要。
:::

## 维度灾难
| 特征数 | 测试准确率 | 最近距离 ÷ 平均距离 |
|---|---|---|
| 13 | 0.963 | 0.24 |
| 63 | 0.926 | 0.65 |
| 213 | 0.741 | 0.83 |
| 1013 | 0.537 | **0.93** |

::: notes
加的是纯随机、无关的特征。维数很高时人人都一样远，“近邻”失去意义。应对：特征选择（第 2 章）、降维（第 8 章）。
:::

# 7.2–7.3 贝叶斯与朴素贝叶斯

## 算一算：检测阳性就一定患病吗？
| 10000 人 | 人数 | 检测阳性 |
|---|---|---|
| 患者（1%） | 100 | 95 |
| 健康人 | 9900 | 495 |
| 合计 | | **590** |

::: notes
先让学生凭直觉猜：很多人会说 95%。答案 95 / 590 ≈ 16.1%。健康人的 5% 误检，绝对人数比真正的患者还多。P(患病) = 1% 是先验概率，P(患病 | 阳性) = 16.1% 是后验概率。贝叶斯定理 P(A|B) = P(B|A)P(A)/P(B)。
:::

## 朴素贝叶斯
- 比较 P(x | 类别) × P(类别)
- 整条短信没法直接数 → **条件独立假设**
- P(短信 | 垃圾) = P(词₁ | 垃圾) × P(词₂ | 垃圾) × …
- 假设不完全对，所以叫“朴素”
- 效果往往仍然不错：只需比较谁大

::: notes
“免费”和“领取”常一起出现，并不独立。连乘会下溢，程序里先取对数再相加，feature_log_prob_ 存的就是对数概率。
:::

## 算一算：“免费 中奖”
| 词 | 垃圾（20 个词） | 正常（30 个词） |
|---|---|---|
| 免费 | 4 次 → 5/30 | 1 次 → 2/40 |
| 中奖 | 3 次 → 4/30 | 0 次 → 1/40 |

::: notes
词表 10 个词，拉普拉斯平滑：(次数 + 1)/(总词数 + 10)。垃圾：0.4 × 5/30 × 4/30 ≈ 0.00889；正常：0.6 × 2/40 × 1/40 = 0.00075。判为垃圾，归一化后约 0.92。
:::

## 拉普拉斯平滑
- “开会”在垃圾短信中 0 次 → 概率 0 → **一票否决**
- 次数都 + 1，分母 + 词表大小
- 66% 的词从没在垃圾短信里出现过
- “Dear Voucher Holder…”：alpha ≈ 0 → **0.000**，alpha = 1 → **1.000**

::: notes
“免费 开会”平滑后：垃圾 0.00222，正常 0.003，P(垃圾) ≈ 0.43。alpha 是超参数，实验 7-2 中 0.1 最好。三种朴素贝叶斯：多项式（词频）、伯努利（0/1）、高斯（连续值）。
:::

## 垃圾短信过滤（实验 7-2）
| 模型 | 精确率 | 召回率 | 漏判 | 误判 |
|---|---|---|---|---|
| 朴素贝叶斯 | 0.967 | **0.911** | 20 | 7 |
| 逻辑回归 | **1.000** | 0.879 | 27 | 0 |

::: notes
两者准确率都是 0.984。最能代表垃圾短信的词：claim（207 倍）、prize、150p、guaranteed、awarded。朴素贝叶斯训练快约十倍。正常短信被拦掉通常更糟，按第 4 章的方法选阈值。
:::

# 7.4 关联规则

## 三个指标
- **支持度** = P(A 且 B)：常不常见
- **置信度** = P(B | A)：准不准
- **提升度** = 置信度 ÷ P(B)：有没有带动
- 提升度 > 1 正相关，= 1 无关，< 1 负相关

::: notes
关联规则是无监督学习。“啤酒与尿布”的故事出处有争议，实验数据中它的支持度太低，连频繁项集都进不了。
:::

## 算一算：10 张小票
| 规则 | 支持度 | 置信度 | 提升度 |
|---|---|---|---|
| 面包 → 牛奶 | 0.4 | 4/5 = 0.8 | 0.8 / 0.5 = **1.6** |
| 啤酒 → 花生 | 0.2 | 2/5 = 0.4 | 0.4 / 0.2 = **2.0** |
| 花生 → 啤酒 | 0.2 | 2/2 = 1.0 | **2.0** |
| 啤酒 → 面包 | 0.1 | 1/5 = 0.2 | **0.4** |

::: notes
小票见教材 7.4.2 节。同一对商品正反两个方向：支持度、提升度相同，置信度不同。证书常错：置信度的分母用成了后件的数量。
:::

## 动手试：关联规则计算器
!sim assoc-rules
- 面包 → 牛奶，再点牛奶 → 面包
- 啤酒 → 面包：提升度 < 1
- 面包、牛奶 → 鸡蛋

::: notes
蓝色是含前件的小票，绿色是前件、后件都含的。让学生先手算再核对。
:::

## 置信度高 ≠ 有关联
- 鸡蛋出现在 **22.6%** 的小票中
- 苹果 → 鸡蛋：置信度 0.249，提升度 **1.10**
- 面包 → 鸡蛋：置信度 0.395，提升度 1.75
- 火锅底料 → 肥牛卷：置信度 0.763，提升度 **11.0**

::: notes
热门商品会出现在一大堆规则的后件里，只看置信度会被误导。提升度明显大于 1 的规则才有价值。
:::

## Apriori 算法
!mermaid 1
- 频繁项集的子集一定频繁
- 花生不频繁 → 含花生的组合都跳过
- 10 张小票：只算 19 个，不剪枝要 255 个

::: notes
最小支持度 0.3：频繁 1 项集 5 个，2 项集 3 个，{面包, 牛奶, 鸡蛋} 支持度 0.2 不频繁。FP-Growth：扫描两遍，压成 FP 树，不生成候选，结果相同；支持度 0.002 时更快。
:::

:::

## 前沿视窗：向量检索
- RAG：文档切段 → 嵌入向量
- 提问也变成向量，找**余弦相似度**最高的几段
- 就是 K 近邻！
- 几百万个向量：**近似最近邻**（HNSW、Faiss）
- 大模型预测下一个词 = 条件概率

::: notes
详见《自然语言处理导论》第 5、11 章。好的嵌入向量把意思相近的内容放得足够近，检索才有效，这也是对维度灾难的回应。
:::
