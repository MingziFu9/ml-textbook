- 营业厅每月有几千名客户**销号转网**

# 1.1 什么是机器学习

## 写规则 vs 从数据中学习
| 对比项 | 写规则 | 机器学习 |
|---|---|---|
| 规则从哪来 | 专家总结、程序员写 | 算法从历史数据中总结 |
| 需要什么 | 清楚的业务知识 | 足够多、足够好的数据 |
| 情况变了 | 人工改规则 | 用新数据重新训练 |
| 适合 | 规则清楚、稳定 | 规则模糊、变量多 |

::: notes
举垃圾短信的例子：“中奖”改成“中ㄐ㈦”，规则就失效了。1959 年塞缪尔的跳棋程序下得比他本人还好，“机器学习”一词由此流行。实际系统往往两者结合：贷款审批中硬性规定用规则，还款可能性用模型打分。
:::

# 1.2 机器学习的基本术语

## 样本、特征与标签
| 花萼长 | 花萼宽 | 花瓣长 | 花瓣宽 | 品种 |
|---|---|---|---|---|
| 5.8 | 4.0 | 1.2 | 0.2 | 山鸢尾 |
| 6.6 | 3.0 | 4.4 | 1.4 | 变色鸢尾 |
| 7.9 | 3.8 | 6.4 | 2.0 | 维吉尼亚鸢尾 |

::: notes
每一行是一个样本，前四列是特征，最后一列是标签。整份鸢尾花数据集 150 个样本，三个品种各 50 个，由费希尔 1936 年使用。强调：同一份数据，标签由问题决定。预测流失时“月消费”是特征，预测话费时它就成了标签。
:::

## 模型、训练与预测
- **模型**：从特征算出标签的函数
- **训练**：用数据确定模型参数（学习、拟合）
- **预测**：把新样本的特征代入模型
- 类比：老中介看过几千套房 = 训练
- 有人来问价，他报出一个数 = 预测

::: notes
模型的形式由算法决定，具体参数从数据中学出来。这一点到第 3 章线性回归会具体看到：形式是 y = wx + b，w 和 b 从数据中学。
:::

## 训练集、测试集与泛化能力
- **泛化能力**：对没见过的新数据的预测能力
- **训练集**：课本和练习题
- **测试集**：期末考试卷，训练时不能看
- 常见比例：训练 70%～80%，测试 20%～30%
- 拿原题考试，背下来也能满分

::: notes
提前点出数据泄露：根据测试集成绩反复修改模型，测试集就变成了训练数据的一部分。第 2 章详细讲。
:::

# 1.3 三种学习范式

## 监督学习：回归与分类
- 训练数据**带标签**
- **回归**：答案是“多少”，如房价、销量
- **分类**：答案是“哪一类”，如流失、垃圾短信
- 判断方法：只看**要预测的东西**，不看特征

::: notes
常见误区：以为特征是数值就是回归。预测门店销量是回归，即使特征全是类别。
:::

## 无监督学习与强化学习
- **无监督学习**：没有标签，自己发现结构
  - 聚类、降维、关联规则、异常检测
- **强化学习**：在环境中试错，靠奖励学习
  - AlphaGo、机器人行走
- 中间情况：半监督学习、自监督学习

::: notes
自监督学习从数据本身构造标签，大模型预训练“预测下一个字”就是例子。
:::

# 1.4 机器学习项目流程

## 从业务问题到机器学习问题
- **要预测什么？** 标签是什么
- **什么时候预测，用什么数据？**
- **是哪类任务？** 分类、回归、聚类
- **怎样算做得好？** 可计算、对应业务的指标
- **做出来怎么用？** 名单推送还是实时显示

::: notes
“减少流失”要翻译成“每月 1 日预测每个客户本月会不会销号”。第二问暗含了防止数据泄露：只能用预测时刻之前已知的信息。对应训练师三级“业务分析”考点。
:::

## 六个步骤
!mermaid 2
- 数据准备往往占一半以上时间
- 两条回头箭头：**反复迭代**
- 先做简单基线，再试复杂模型

::: notes
新手最常犯的错误是一上来就挑最复杂的模型。评估不满意回到数据准备，上线后效果下降回到问题定义。
:::

## 例子：客户流失预警
| 步骤 | 做什么 | 本书练习 |
|---|---|---|
| 问题定义 | 每月预测本月是否流失 | 本节 |
| 数据准备 | 取客户资料，查缺失、异常 | 第 2 章 |
| 建模 | 逻辑回归做基线，再试树模型 | 实验 4-1、5-2 |
| 评估 | 比 AUC、调阈值、写测试报告 | 实验 4-2、5-3 |
| 部署监控 | 每月推送名单，定期重训 | 实验 9-3 |

::: notes
这张表是全书的地图。后面每学一种方法，都请学生想一想它在流程的哪一步发挥作用。
:::

# 1.5 简史与工具

## 机器学习简史
- 1958 感知机：第一个会学习的神经网络
- 1986 ID3 决策树、反向传播
- 1995 支持向量机；2001 随机森林
- 2012 AlexNet：深度学习突破
- 2016 AlphaGo；2017 Transformer
- 2022 ChatGPT；2025 DeepSeek-R1 开源

::: notes
两条线索：方法越来越强，从人工设计特征到自动学习特征；数据和算力越来越重要。简史可以布置为课后阅读。
:::

## scikit-learn 的四步
```python
model = KNeighborsClassifier(n_neighbors=5)  # 创建，设超参数
model.fit(X_train, y_train)                  # 训练
y_pred = model.predict(X_test)               # 预测
acc = model.score(X_test, y_test)            # 评估
```
::: notes
所有模型用法相同，换算法只改第一行。`n_neighbors=5` 是超参数：训练前由人设定，不由模型学习。分类模型的 score 返回准确率，回归模型返回 R²。
:::
