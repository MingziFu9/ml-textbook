# 4.1–4.2 逻辑回归

## 分类问题
- **二分类**：流失 / 不流失，恶性 / 良性，欺诈 / 正常
- **正类**：要找出来的那一类，记为 1，“正”不表示“好”
- **多分类**：手写数字 0～9
- 线性回归做分类的毛病：输出不在 0～1 之间

::: notes
逻辑回归名字里有“回归”，却是分类模型，这是证书判断题的常见陷阱。
:::

## 从线性回归到 Sigmoid
!mermaid 1
- z = w₁x₁ + … + b
- p = 1 / (1 + e⁻ᶻ)，在 0～1 之间
- z = 0 → p = 0.5

::: notes
算一算：z = 2 时 p ≈ 0.881，z = −2 时 p ≈ 0.119。实验 4-1 第 1 个客户 C101053，z = −0.204，p ≈ 0.449，判为不流失但不太确定。predict_proba 取概率，predict 按 0.5 判类别。
:::

## 决策边界与交叉熵
- 阈值 0.5 ⇔ z ≥ 0，**决策边界**是一条直线
- 逻辑回归是**线性分类器**
- **交叉熵**：正确类别概率的负对数
- p = 0.9 → 0.105；0.5 → 0.693；**0.1 → 2.303**
- 越有把握地判错，惩罚越重

::: notes
交叉熵没有现成公式，用梯度下降求解。ConvergenceWarning 一般是没标准化或 max_iter 不够。LogisticRegression 默认带 L2 正则化，C 越小正则化越强，方向与 Ridge 的 alpha 相反。
:::

## 系数解读：几率与倍数
| 特征（已标准化） | 系数 | e^系数 |
|---|---|---|
| 合约类型_月付 | 0.703 | 2.02 |
| 近半年投诉次数 | 0.501 | 1.65 |
| 月消费 | 0.381 | 1.46 |
| 合约类型_两年 | −0.746 | 0.47 |
| 在网月数 | −1.051 | 0.35 |

::: notes
几率 = 发生概率 ÷ 不发生概率。特征增加 1 个单位（这里是一个标准差），几率变为 e^w 倍。在网月数每长约 16 个月，流失几率降为 0.35 倍。业务建议：关注月付、投诉多、入网短的客户，推动改签长期合约。
:::

## 多分类：Softmax
- 一对多：K 个二分类器，取概率最大的
- **Softmax**：K 个得分 → 和为 1 的概率
- 得分 2.0、1.0、0.1 → 概率 **0.66、0.24、0.10**
- 神经网络分类的最后一层也是 Softmax + 交叉熵

::: notes
e² ≈ 7.389，e¹ ≈ 2.718，e^0.1 ≈ 1.105，和 11.212。取指数把差距拉大。二分类时 Softmax 与 Sigmoid 等价。
:::

# 4.3 混淆矩阵与分类指标

## 混淆矩阵（实验 4-1，阈值 0.5）
| | 预测流失 | 预测不流失 |
|---|---|---|
| 实际流失（455） | TP = 264 | FN = 191（漏掉） |
| 实际不流失（1045） | FP = 147（误报） | TN = 898 |

::: notes
记法：第二个字母是“预测成什么”，第一个字母是“预测对没对”。FN 是预测成负类但错了，即漏掉的正类。注意 sklearn 的 confusion_matrix 第一行是实际为 0，ravel() 顺序是 TN、FP、FN、TP。
:::

## 四个指标
- **准确率** = (TP + TN) / 全部 = 1162 / 1500 ≈ **0.775**
- **精确率** = TP / (TP + FP) = 264 / 411 ≈ **0.642**：判得准不准
- **召回率** = TP / (TP + FN) = 264 / 455 ≈ **0.580**：找得全不全
- **F1** = 2PR / (P + R) ≈ **0.610**：调和平均

::: notes
回答客户经理：打 100 个电话约 64 个打给真要走的人；455 个要走的人找出了 58%。F1 用调和平均：精确率 1.0、召回率 0.1 时普通平均 0.55，F1 只有 0.18。证书最常错：精确率除以“预测为正”，召回率除以“实际为正”。
:::

## 什么时候看哪个指标
| 指标 | 最看重的场合 |
|---|---|
| 准确率 | 各类数量差不多、错误代价差不多 |
| 精确率 | 误报代价高：垃圾短信拦截 |
| 召回率 | 漏报代价高：癌症筛查、盗刷识别 |
| F1 值 | 两者兼顾，要一个数比较模型 |

::: notes
让学生再举自己工作中的例子，说出漏判和误判各是什么、哪个代价高。
:::

# 4.4 分类阈值、ROC 与 PR 曲线

## 阈值：此消彼长
| 阈值 | 漏诊 FN | 误诊 FP | 精确率 | 召回率 |
|---|---|---|---|---|
| 0.1 | 1 | 25 | 0.716 | 0.984 |
| 0.3 | 3 | 10 | 0.859 | 0.953 |
| 0.5 | 9 | 4 | 0.932 | 0.859 |
| 0.9 | 22 | 0 | 1.000 | 0.656 |

::: notes
乳腺肿瘤诊断数据，测试集 171 例（恶性 64 例），5 个特征的逻辑回归。阈值调低，漏诊少、误诊多。选阈值是业务问题：癌症初筛要保召回率，取 0.3 左右；垃圾短信要保精确率，阈值调高；流失挽留按概率排序、能打多少打多少，前 50 名命中 48 人。
:::

## ROC 曲线与 AUC
![ROC 与 PR 曲线](img/lab4_2_roc_pr.png)
- 横轴假阳性率，纵轴召回率
- 越靠**左上角**越好
- AUC：正类排在负类前面的概率
- 5 个特征 0.980，30 个特征 0.998

::: notes
AUC 0.5 等于乱猜，1 是完美。AUC 与阈值无关：先比 AUC 选模型，再按业务选阈值。PR 曲线的随机基线是正类比例（这里 0.374）。
:::

# 4.5 类别不平衡

## 准确率陷阱
- 2 万笔交易，欺诈只占 **1.04%**
- 全部判为正常：准确率 **0.990**，一笔也抓不到
- 逻辑回归不处理：准确率 0.991，召回率只有 **0.270**
- 正类很少时看召回率、精确率、**PR 曲线**
- AUC 0.962 看着好，AP 只有 **0.487**

::: notes
模型偏向多数类，是因为损失是所有样本的平均，146 笔欺诈在 14000 笔里占比太小。正类很少时 ROC 的横轴分母是几千笔正常交易，多误报几百笔也只增加一点点，PR 曲线更能说明问题。
:::

## 三类处理方法
| 做法 | 召回率 | 精确率 | 误报 | AP |
|---|---|---|---|---|
| 不处理 | 0.270 | 0.739 | 6 | 0.487 |
| 类别权重 balanced | 0.841 | 0.074 | 663 | 0.467 |
| 随机欠采样 | 0.873 | 0.063 | 813 | 0.446 |
| SMOTE 过采样 | 0.841 | 0.077 | 638 | 0.482 |

::: notes
SMOTE 在少数类样本和它的近邻之间连线取点，合成新样本。铁律：采样只能用于训练集，用 imblearn 的流水线。四种做法 AP、AUC 几乎一样：处理方法主要是降低了判为欺诈的门槛，没有让模型更会区分。只把阈值降到 0.1，召回率也能到 0.587。
:::

## 按业务代价选方案
| 方案 | 漏判 | 误报 | 总代价（元） |
|---|---|---|---|
| 不用模型 | 63 | 0 | 42318 |
| 不处理 | 46 | 6 | 26172 |
| 类别权重 | 10 | 663 | 15633 |
| 类别权重 + 阈值 0.8 | 21 | 176 | **12157** |

::: notes
漏判损失 = 漏掉的欺诈金额，误报成本按每笔核实电话 20 元。“类别权重 + 阈值 0.8”总代价最低，比不用模型节省约七成。误报成本变了，最优方案也会变。评价指标是手段，业务代价才是目的。
:::

# 4.6 错误案例分析与测试报告

## 错误案例分析
- 逐条看**漏判**和**误报**的样本
- 漏判的欺诈：金额小（中位数 149 元）、无设备变化
- 误报的正常交易：金额偏大、交易频繁、换过设备
- 改进：加入“短时间多商户交易次数”等特征
- 步骤：列错例 → 对比 → 查原始记录 → 归纳建议

::: notes
查原始记录时要判断是模型的问题、特征不够，还是标签本身标错了。对应训练师三级“分析错误案例”。
:::

## 模型测试报告六部分
- **测试目的**：解决什么问题，怎样使用
- **测试数据**：来源、规模、类别比例、划分
- **评价指标**：用哪些、为什么
- **测试结果**：对比表、混淆矩阵、曲线
- **错误案例分析**：典型案例和原因
- **结论与建议**：推荐方案、效果、局限、改进

::: notes
三点要求：结论先行；用业务语言，“召回率 0.667”写成“63 笔欺诈中抓住 42 笔”；如实写局限。实验 4-3 的实验报告就是写这份报告。
:::

## 前沿视窗
- **离线指标 ≠ 上线效果**：用 A/B 测试说话
- **大模型做分类**：提示词零样本、少样本分类
- 评估方法不变：测试集、混淆矩阵、测试报告
- **公平性**：分人群看误判率

::: notes
A/B 测试：随机分两组，一组用新模型，一组用旧办法，比较业务指标。大模型分类见《自然语言处理导论》第 6 章前沿视窗。
:::
