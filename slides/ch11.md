# 11.1 图像在计算机中的样子

# 11.2 卷积与池化

## 算一算：手算 3×3 卷积
| 0 | 0 | 1 | 1 | 1 |
|---|---|---|---|---|
| 0 | 0 | 1 | 1 | 1 |
| 0 | 0 | 1 | 1 | 1 |

## 步长、填充与特征图大小
- 特征图边长 = (n + 2p − k) ÷ s + 1
- 5×5、3×3 核：不填充 3；填充 1 得 5；填充 1 步长 2 得 3
- 3×3 核 + 填充 1：大小不变（`padding="same"`）

::: notes
填充的副作用：补的 0 造出“假边”，特征图最右一列出现 −3。
:::

## 为什么卷积适合图片
| 层（输入 28×28） | 参数 |
|---|---|
| 全连接，128 个神经元 | 100 480 |
| 卷积，16 个 3×3 核 | **160** |
| 卷积，16 → 32 通道 | 4640 |

- **局部连接**、**参数共享**
- 参数个数与图片大小无关

::: notes
参数公式：核高 × 核宽 × 输入通道 × 核个数 + 核个数。
:::

# 11.3 卷积神经网络的结构

## 卷积—池化—全连接
| 层 | 输出形状 | 参数 |
|---|---|---|
| 卷积 16 个 3×3 + ReLU | 16×28×28 | 160 |
| 最大池化 | 16×14×14 | 0 |
| 卷积 32 个 3×3 + ReLU | 32×14×14 | 4640 |
| 最大池化 | 32×7×7 | 0 |
| 拉平 → 全连接 64 → 全连接 10 | 10 | 101 066 |

- 越往后：特征图越小、通道越多

::: notes
训练方法与第 10 章一样：交叉熵、Adam、四步循环。
:::

## CNN vs 多层感知机（Fashion-MNIST）
| 模型 | 参数 | 测试准确率 | 用时 |
|---|---|---|---|
| MLP | 101 770 | 0.847 | 2 秒 |
| CNN（PyTorch） | 105 866 | **0.877** | 24 秒 |
| CNN（Keras） | 105 866 | 0.871 | 24 秒 |

- 全量 55 000 张训练：同一网络 **0.909**

::: notes
CNN 参数 95% 在第一个全连接层，两个卷积层只有 4800 个。
:::

# 11.4 数据增强与迁移学习

## 数据增强：变换要符合实际
- 翻转、旋转、平移、调亮度……
- 实测：给服装图加左右翻转，测试 0.877 → **0.868**
- 原因：数据集中鞋子都朝左
- 先问：变换后的图实际会出现吗？

::: notes
手写数字也不能翻转。增强减轻了过拟合（差距 0.036 → 0.029），但方向错了。
:::

## 序列、时间步、隐藏状态

## 算一算：RNN 读“中奖 了 这 是 上次”
- hₜ = tanh(1.5 xₜ + 0.5 hₜ₋₁)
- h₁ = 0.905 → 0.424 → 0.209 → 0.104 → **0.052**
- 每读一个中性词，记忆缩小一半多
- 往回传 15 步，梯度只剩 2.4 × 10⁻⁵

::: notes
长期依赖。乘的数大于 1 时梯度爆炸，用梯度裁剪处理。
:::

# 11.6 LSTM 与 GRU

## LSTM 的三个门
| 门 | 作用 |
|---|---|
| 遗忘门 f | 旧记忆留多少 |
| 输入门 i | 新内容写多少 |
| 输出门 o | 输出多少记忆 |

- cₜ = f × cₜ₋₁ + i × g
- 同一例子：c 从 0.964 → 0.893 → … → **0.710**

::: notes
门的值由网络学出来。沿记忆细胞往回传每步只乘 f，f 接近 1 时梯度不易消失。
:::
