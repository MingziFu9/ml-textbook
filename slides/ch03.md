# 3.1–3.2 一元线性回归

## 回归问题与线性回归
- 回归：预测一个**数**，错多错少不一样
- 房价、销量、送达时间、保费
- “回归”来自高尔顿：子女身高向平均值回归
- 一元线性回归：ŷ = **w** x + **b**
- w 权重：每多 1 平方米多多少万元；b 偏置

::: notes
线性回归计算快、容易解释，至今仍大量用于房价评估、销量预测，也常作为复杂模型的对照组。
:::

## 损失函数：均方误差
- 残差 = 真实值 − 预测值
- MSE = 残差平方的**平均**
- 为什么平方？正负不抵消，大误差放大
- 直线甲“总价 = 3 × 面积”：MSE = **300**
- 直线乙“总价 = 2.5 × 面积 + 35”：MSE = **40**
- 还有更好的吗？

::: notes
用 5 套房子（面积 50～130，总价 160～360）现场算两条直线的残差。直线乙有 3 个点完全命中，但还不是最好的。引出最小二乘。
:::

## 算一算：手算最小二乘
| 面积 x | 总价 y | x − 90 | y − 260 | 乘积 | (x − 90)² |
|---|---|---|---|---|---|
| 50 | 160 | −40 | −100 | 4000 | 1600 |
| 70 | 210 | −20 | −50 | 1000 | 400 |
| 90 | 250 | 0 | −10 | 0 | 0 |
| 110 | 320 | 20 | 60 | 1200 | 400 |
| 130 | 360 | 40 | 100 | 4000 | 1600 |

::: notes
w = 10200 / 4000 = 2.55，b = 260 − 2.55 × 90 = 30.5。总价 = 2.55 × 面积 + 30.5。残差 2、1、−10、9、−2，MSE = 190 / 5 = 38，比直线乙的 40 还小。请学生带计算器跟着算。公式只对线性回归成立，特征多了算矩阵逆很慢，其他模型没有公式，所以需要梯度下降。
:::

# 3.3 梯度下降

## 蒙眼下山
- 损失函数是一座山，高度 = 损失
- **梯度**：脚下最陡的方向
- 沿梯度**反方向**迈一小步
- w ← w − 学习率 × ∂L/∂w
- 线性回归的损失是“碗”，只有一个谷底

::: notes
算一算：面积标准化后从 w = 0、b = 0 出发，损失 72840；b 的梯度 −520，w 的梯度 −144.25，学习率 0.1 走一步后 b = 52、w ≈ 14.42，损失 46631。200 步后 w = 72.12、b = 260，换算回去正是 2.55 和 30.5。
:::

## 学习率：步子迈多大
![学习率与损失曲线](img/lab3_1_lr.png)
- 0.01：太小，20 步后损失还有 33820
- 0.5：合适，20 步到谷底 38
- 0.9：偏大，来回跳
- 1.05：太大，**发散**

::: notes
学习率是超参数，第 9 章讲怎样选。训练时画损失曲线是判断学习率最直接的办法：平稳下降合适，下降很慢偏小，忽高忽低或一路上升偏大。
:::

## 动手试：梯度下降下山
!sim gradient-descent
- 依次试 0.01、0.5、0.9、1.05
- 再点“不标准化”
- 看红线走过的路

::: notes
不标准化时损失地形是又窄又长的峡谷：学习率 0.0001 走 200 步后 b 只有 0.138，0.0002 就发散。这就是梯度下降前要做特征缩放的原因。
:::

## 批量、随机、小批量
| 方法 | 每次用样本 | 20 轮更新 | 第 20 轮 MSE |
|---|---|---|---|
| 批量 | 2400 | 20 次 | 18936.4 |
| 小批量 | 32 | 1500 次 | 17680.3 |
| 随机（SGD） | 1 | 48000 次 | 18476.7 |

::: notes
最优 MSE 是 17606.1。批量梯度下降更新次数太少，还没到谷底；随机梯度下降方向抖动，停不稳；小批量兼顾速度和稳定，是今天最常用的做法，大模型训练用的也是它。一轮（epoch）= 全部样本用过一遍。
:::

# 3.4 多元线性回归与回归评价

## 多元线性回归的系数
| 特征 | 系数 | 含义（其他不变时） |
|---|---|---|
| 面积 | 2.98 | 每多 1 平方米多约 3 万元 |
| 距地铁站_千米 | −14.29 | 每远 1 千米少约 14 万元 |
| 区域_天河 | 354.08 | 比南沙贵约 354 万元 |
| 装修_毛坯 | −25.08 | 比“未知”便宜约 25 万元 |

::: notes
三点注意：其他特征不变；系数大小受单位影响，不能直接比重要性，要比先标准化；截距 −4505.2 对应“建成年份为 0”，没有实际意义。
:::

## 多重共线性
- “室”的系数只有 **2.49**？
- “室”与“面积”相关系数 **0.845**
- 只用“室”：系数 **75.30**
- 特征高度相关 → 系数不稳定、难解释
- 办法：去掉重复特征，或用岭回归

::: notes
多重共线性通常不太影响预测准确度，但用系数做“哪个因素影响大”的分析时要特别小心。
:::

## 回归评价指标
- **MAE**：平均每套错多少万元
- **RMSE**：MSE 开平方，大误差影响更大，RMSE ≥ MAE
- **R²** = 1 − 模型误差平方和 / 猜平均值误差平方和
- R² = 1 完美，= 0 等于猜平均，< 0 不如猜平均
- R² 常和 MAE 或 RMSE 一起报告

::: notes
证书常考：给出几个真实值和预测值算 MAE、MSE、RMSE；RMSE 忘开平方；r2_score 参数写反结果会变。
:::

## 实验 3-2 的结果
| 模型 | MAE | RMSE | R² |
|---|---|---|---|
| 基线：猜平均值 | 124.2 | 163.7 | −0.000 |
| 线性回归（训练集） | 45.2 | 61.9 | 0.848 |
| 线性回归（测试集） | 47.9 | 66.2 | 0.836 |
| 预测 log(总价) | 34.9 | 49.2 | 0.910 |

::: notes
训练集和测试集成绩接近，没有过拟合。平均错 48 万元对一套 280 万元的房子还偏大，残差图告诉我们问题在哪。
:::

## 残差图：发现模型漏掉的规律
![残差图](img/lab3_2_residual.png)
- 左：**喇叭口**，高价房误差大
- 左：低价处弯曲，10 套预测为负
- 根源：总价更像“单价 × 面积”
- 右：预测 log(总价) 后明显改善

::: notes
预测价 < 200 万的平均绝对残差 30.4 万元，> 500 万的 125.9 万元。改进一：加交叉特征“区域参考单价 × 面积”，R² 0.901；改进二：预测 log(总价)，R² 0.910，天河系数 1.232，即约为南沙的 3.43 倍。读懂残差图再改特征，往往比换复杂模型更有效。
:::

# 3.5 过拟合与正则化

## 欠拟合与过拟合
![阶数与误差](img/lab3_3_degree.png)
- 1 阶：训练、测试都差 → **欠拟合**
- 2 阶：测试 MSE 最小 529.4
- 15 阶：训练 155.8，测试四千多万 → **过拟合**

::: notes
奶茶店 20 天数据，真实规律“先升后降”。15 阶曲线为了穿过每个训练点剧烈扭动，在 32～36 ℃ 之间没有训练数据的地方冲到 0 以下。射箭比喻：欠拟合是偏差大（箭箭偏一边），过拟合是方差大（手抖）。测试 MSE 低不过随机波动的方差 400。
:::

## 动手试：多项式阶数与过拟合
!sim poly-overfit
- 阶数从 1 拖到 15
- 固定 15 阶，alpha 从 0 调到 100
- 看曲线和两个误差

::: notes
让学生找出测试 MSE 最小的阶数，对照实验 3-3。alpha = 100 时曲线太平，正则化太强也会欠拟合。
:::

## 正则化：岭回归与 Lasso
- 过拟合的模型**系数特别大**（15 阶系数之和 165 万）
- 损失 = MSE + α × 惩罚项
- **岭回归**（L2）：系数平方和，整体变小、不为 0
- **Lasso**（L1）：系数绝对值和，部分压成 **0**
- α 越大越简单；先标准化；α 用验证集选

::: notes
实验 3-3：岭回归 α = 1 测试 MSE 512.5，比 2 阶还略好；Lasso α = 1 把 15 个系数中 12 个压成 0，只留 x、x² 和 x¹⁵，正好是“先升后降”的形状。Lasso 能做特征选择，就是第 2 章说的嵌入法。注意：正则化会让训练误差变大。
:::

## 前沿视窗：从 2 个参数到几千亿个
- 大模型训练用的仍是**梯度下降**
- 小批量：一次几百万个字
- 成千上万块 GPU 并行算梯度
- Adam：每个参数自己的步长
- 自动求导：写出计算过程，梯度自动算

::: notes
工程师训练大模型最关心的也是本章的事：学习率怎样设置和逐步调小，损失曲线有没有突然“炸掉”。第 10 章用 PyTorch 体验自动求导。
:::
