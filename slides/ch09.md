# 9.1 偏差、方差与学习曲线

## 偏差与方差
- **偏差**：想法本身不对 → 欠拟合
- **方差**：对训练数据太敏感 → 过拟合
- 射手比喻：偏差大打得集中但偏了；方差大东一枪西一枪
- 模型越复杂：偏差 ↓，方差 ↑

::: notes
调模型就是在两者之间找平衡。
:::

## 学习曲线：诊断
![四条学习曲线](img/lab9_1_learning_curves.png)
- 两条线都低、贴在一起 → **偏差大**（线性回归 0.841 / 0.837）
- 训练高、验证低、隔一大段 → **方差大**（不限深度的树 1.000 / 0.707）

::: notes
偏差大：换复杂模型、加特征、减弱正则化，加数据没用。方差大：加数据、简化模型、加强正则化。梯度提升树验证得分随样本还在上升，多收集数据还有用。
:::

# 9.2 交叉验证

## 一次划分不够
- 同一个模型，10 种随机划分：**0.769～0.797**
- 5 折交叉验证：0.790、0.776、0.800、0.749、0.783
- 平均 **0.780**，标准差 0.017
- 每个样本恰好当一次验证

::: notes
逻辑回归与 LightGBM 只差 0.008，比一次划分的波动还小，不能下结论。
:::

## 分层 K 折
| 200 条，流失率 24% | 五折验证集的流失率 |
|---|---|
| 普通 K 折 | 22.5%、27.5%、27.5%、**17.5%**、25.0% |
| 分层 K 折 | 22.5%、22.5%、25.0%、25.0%、25.0% |

::: notes
分层抽样：每一份的类别比例与整体一致。cross_val_score 遇到分类模型默认用分层 K 折。
:::

# 9.3 超参数调优

## 网格搜索、随机搜索、Optuna
- 参数：学出来的；**超参数**：训练前设定的
- 网格搜索：试遍所有组合（3 × 4 × 3 = 36）
- 随机搜索：范围内随机抽
- Optuna：根据已有结果，往好的区域试

::: notes
5 个超参数各 5 个值就是 3125 种组合。随机搜索在同样次数下每个超参数能试到更多取值。
:::

## 调参的收益有多大
| 方法 | 交叉验证 AUC | 测试 AUC |
|---|---|---|
| 梯度提升树默认 | 0.842 | |
| 网格 / 随机 / Optuna | 0.863～0.865 | 0.829～0.835 |
| 逻辑回归（不调参） | **0.866** | **0.836** |

::: notes
三种方法差别不到 0.002，都选了深度 2。调参发挥潜力，但不能突破数据的上限：先做数据和基线，再试模型，最后调参。交叉验证分数比测试高约 0.03，是挑选带来的乐观。
:::

# 9.4 流水线：防止数据泄露

## 数据泄露：随机数据也能“学会”
- 200 条、1000 个随机特征、标签随机
- 先在全部数据上选特征再交叉验证：**0.740**
- 每一折里面选：**0.415**
- 原则：从数据“学”东西的预处理只在训练部分 fit

::: notes
标准化、填充、过采样、PCA 都一样，只是影响通常小一些。
:::

# 9.5 模型解释

## 置换重要性
- 打乱一列，看测试 AUC 降多少
- 合约类型 **0.140**，在网月数 0.056，投诉次数 0.022
- 累计消费约 0：与“在网月数 × 月消费”相关 0.999

::: notes
置换重要性对任何模型都适用、在测试集上算；第 5 章的不纯度重要性在训练集上算、偏爱取值多的特征。
:::

## SHAP：这位客户为什么高风险
| 项目 | 贡献（对数几率） |
|---|---|
| 基准值 | −1.341（约 0.21） |
| 在网 2 个月 | **+1.402** |
| 月付 | +0.896 |
| 投诉 2 次 | +0.641 |
| 合计 2.774 | 概率 **0.941** |

::: notes
SHAP 来自博弈论的公平分配：输出 = 基准值 + 各特征贡献。可以对客户经理说：刚来两个月、按月付费、投诉两次。解释不等于因果。
:::

## 上线以后：数据漂移
| 特征 | PSI | 判断 |
|---|---|---|
| 月消费（涨价 15%） | 0.313 | 明显漂移 |
| 合约类型 | 0.161 | 轻微漂移 |
| 其他 8 个 | ≤ 0.024 | 稳定 |

::: notes
PSI < 0.1 稳定，0.1～0.25 轻微，> 0.25 明显。监控四件事：输入、输出、实际效果、定期重训。平均流失概率 0.310 → 0.369。
:::
