# 附录 C 实验环境、数据与算力说明

## C.1 软硬件要求

本书 36 个实验**全部在普通笔记本电脑的 CPU 上完成，不需要显卡**，书中的运行结果都是编者实际运行得到的。编者的运行环境是 4 核 CPU、Linux、Python 3.11，各实验用时从不到 1 秒到约 1 分钟；最慢的是实验 11-2（两个卷积网络各训练约 24 秒）。

| 项目 | 最低要求 | 建议 |
|---|---|---|
| 电脑 | 双核 CPU、8 GB 内存 | 4 核以上 CPU、16 GB 内存 |
| 操作系统 | Windows 10、macOS 12、主流 Linux | 同左 |
| 硬盘 | 剩余 5 GB（PyTorch 约占 1～3 GB） | 10 GB |
| Python | 3.10 | 3.11（与编者一致） |
| 显卡 | 不需要 | 有 NVIDIA 显卡时 PyTorch 会更快，但实验不依赖它 |

如果电脑配置较低或不方便安装软件，可以用在线 Notebook 平台，浏览器打开就能写代码，都提供免费的 CPU 环境：百度飞桨 AI Studio、阿里云天池实验室、魔搭社区（ModelScope）Notebook。把 `labs/` 目录上传到平台，再安装缺少的库即可（实验 1-1）。

不同电脑、不同版本的库，随机数可能不同，你的运行结果和书上的数字可能有小的差别，规律和结论是一样的。涉及神经网络的实验（第 10～12 章）差别相对大一些。

## C.2 安装步骤

**1. 安装 Python。**从 Python 官网或国内镜像下载 3.11 版本；Windows 安装时勾选“Add Python to PATH”。也可以安装 Anaconda 或 Miniconda。

**2. 建一个专门的虚拟环境**，避免和电脑上其他软件的库冲突：

```bash
python -m venv mlenv                 # 新建名为 mlenv 的虚拟环境
mlenv\Scripts\activate               # Windows 激活
source mlenv/bin/activate            # macOS / Linux 激活
```

**3. 安装工具库。**在仓库根目录运行（使用清华大学镜像，国内下载更快）：

```bash
pip install -r labs/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

`requirements.txt` 中写的是编者实测的版本，见[附录 B](b-libraries.md)。PyTorch 默认安装包较大；只用 CPU 时，可以按 PyTorch 官网的说明安装 CPU 版，体积小很多。

**4. 检查环境。**进入 `labs/ch01` 目录，运行 `python check_env.py`，它会逐个检查各库能否导入并打印版本号，最后用鸢尾花数据训练一个小模型（实验 1-1）。

**5. 打开 Jupyter。**运行 `jupyter lab`，在浏览器中新建 Notebook，把实验代码分段粘贴运行；也可以直接在命令行运行 `.py` 文件。**实验代码都要在它所在的目录下运行**（例如先 `cd labs/ch05`），因为代码用相对路径 `../data/` 读数据。

**中文显示。**实验代码画图时会依次尝试黑体、微软雅黑、苹方、文泉驿、思源黑体等中文字体。Windows 和 macOS 自带其中之一；Linux 上如果图中的中文显示成方框，安装 `fonts-noto-cjk` 或 `fonts-wqy-zenhei` 即可。

## C.5 需要联网或特殊条件的实验

本书没有需要 GPU 或大模型 API 的实验，也没有“待实测”的实验。下面几个实验有额外的条件：

| 实验 | 需要什么 | 说明 |
|---|---|---|
| 实验 1-1 | 联网 | 安装 Python 和工具库 |
| 实验 9-3 | 本机启动网络服务 | FastAPI 接口和 Gradio 网页在本机运行（`127.0.0.1`），不需要公网；端口被占用时换一个端口 |
| 实验 11-2 | 第一次运行时联网 | 自动下载 Fashion-MNIST，见 C.3 |
| 实验 12-3 | 图形界面（可选） | 想看智能体走动画面时用 `render_mode="human"`，需要图形界面；默认不显示画面，不需要 |

学校的 GPU 服务器可用于课堂演示，比如用全部 60 000 张图片训练实验 11-2 的卷积网络（CPU 上约 2 分钟，测试准确率 0.909），或训练更深的网络。

## C.6 课时安排建议
