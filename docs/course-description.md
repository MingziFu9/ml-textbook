## 课程描述

以下照录《人工智能技术应用专业人才培养方案（2026）》中的课程描述：

!!! quote "人才培养方案 · 19. 机器学习"
    本课程旨在介绍机器学习的基本概念、算法和应用，帮助学生掌握从数据分析到模型建立和评估的全过程。学生将学习到监督学习、无监督学习和强化学习等主要学习范式，以及它们在实际中的应用场景和案例。

    课程内容涵盖了数据预处理、特征工程、模型选择与评估等关键步骤。学生将通过理论讲解和实验实践掌握常见的机器学习算法，如线性回归、逻辑回归、决策树、支持向量机、聚类算法等。此外，课程还将涉及到深度学习的基本原理和常见模型（如神经网络、卷积神经网络、循环神经网络等）的实现与优化技巧。

    通过实际项目和案例分析，学生将学会如何选择合适的算法和工具，以及如何处理真实世界中复杂和大规模的数据集。课程还将强调数据驱动的决策和模型部署的实际操作。最终，学生将具备在各种领域应用机器学习技术的能力，为其在科技行业和学术研究中的进一步发展提供坚实的基础和实践经验。

## 本书怎样落实

机器学习是让计算机从数据中自己总结规律、再用规律去做预测和决策的技术。银行判断一笔贷款会不会违约，电商预测下个月卖多少货，外卖平台估算送达时间，医院辅助筛查病灶，背后都是机器学习模型。今天的大模型、人脸识别、语音助手，也都建立在机器学习的基本思想之上。对人工智能技术应用专业的学生来说，机器学习是后续“人工智能开发框架技术”“人工智能数据分析与处理”“计算机视觉”“语音技术”等课程的共同基础，也是 AI 训练师、数据处理工程师等岗位每天要用的本领。

本课程坚持“够用、能用、会用”的原则：每个算法先讲清楚它在解决什么问题、直观上怎么想，再给出最必要的公式和一个可以手算的小例子，最后落到 scikit-learn 等工具上动手做。课程按一个机器学习项目的完整流程组织：从认识数据、清洗数据、构造特征开始，学习回归、分类、聚类、降维、关联规则等经典算法，掌握模型评估、交叉验证和调参，再进入神经网络、卷积神经网络、循环神经网络的基础，最后学习时间序列预测、强化学习入门，并把训练好的模型保存下来、做成一个可以调用的小服务。

全书 12 章、36 个实验。实验以普通笔记本电脑上的 CPU 和小规模数据为主，也可以在百度 AI Studio、魔搭等免费云平台上完成；需要更大算力的拓展内容标明使用云算力。实验报告按“测试报告 + 错误案例分析”的格式撰写，与人工智能训练师（三级）“智能训练”模块的工作要求一致。

学完本课程，学生能够独立完成一个中小规模机器学习项目的全过程：理解业务问题、准备数据、选择并训练模型、评估和改进模型、解释结果并写出报告，还能把模型交给别人使用。

## 主要内容

- 机器学习的概念、三种学习范式（监督、无监督、强化）与项目工作流程
- 数据预处理：缺失值、异常值、重复值、数据类型转换、标准化与归一化、类别编码
- 特征工程：特征构造、特征选择、数据集划分与数据泄露
- 回归：线性回归、多项式回归、正则化（岭回归、Lasso）、梯度下降、回归评价指标
- 分类：逻辑回归、决策树、随机森林、梯度提升（XGBoost、LightGBM）、支持向量机、K 近邻、朴素贝叶斯
- 分类评价：混淆矩阵、准确率、精确率、召回率、F1、ROC 与 AUC、类别不平衡
- 无监督学习：K-Means、层次聚类、DBSCAN、主成分分析（PCA）、t-SNE 可视化
- 关联规则：支持度、置信度、提升度、Apriori 算法、购物篮分析
- 模型选择与调优：偏差与方差、过拟合与欠拟合、交叉验证、网格搜索与随机搜索、流水线、模型保存与简单部署
- 神经网络基础：感知机、多层感知机、激活函数、损失函数、反向传播的直观理解、优化器
- 卷积神经网络与循环神经网络的基本结构与应用（PyTorch 与 Keras 两套代码）
- 时间序列预测：趋势与季节性、滑动窗口、ARIMA 的直观理解、基于特征的预测、LSTM 预测
- 强化学习入门：智能体、环境、奖励、Q 学习
- 机器学习中的可解释性、公平性与数据合规

## 不涉及的内容

- 复杂的数学推导（支持向量机对偶问题、反向传播的矩阵求导、EM 算法证明等）
- 概率图模型、高斯过程、贝叶斯优化等研究生层次内容
- 深度学习进阶（自编码器、生成对抗网络、注意力机制与 Transformer），这些内容归“神经网络与深度学习”和“自然语言处理”课程
- 深度学习框架的系统用法、GPU 训练、模型压缩与生产部署，归“人工智能开发框架技术”课程
- 分布式机器学习（Spark MLlib），归“大数据技术处理技术”课程
- 推荐系统的完整实现、数据标注规范与工具，归“人工智能数据分析与处理”课程
- 网页数据采集，归“网络爬虫技术”课程

## 学习目标

完成本课程后，学生能够：

### 记忆（Remember）

- 说出机器学习的定义，以及监督学习、无监督学习、强化学习的区别和各自 3 个以上的应用场景
- 列举机器学习项目的基本步骤：问题定义、数据准备、特征工程、建模、评估、部署
- 复述样本、特征、标签、训练集、验证集、测试集、过拟合等基本术语
- 列出回归和分类任务的常用评价指标（MAE、RMSE、R²，准确率、精确率、召回率、F1、AUC）
- 识别线性回归、逻辑回归、决策树、随机森林、XGBoost、SVM、KNN、朴素贝叶斯、K-Means、PCA、Apriori、CNN、RNN、LSTM 等算法名称及其所属类别

### 理解（Understand）

- 用自己的话解释“从数据中学习”和“写规则”的区别
- 解释梯度下降如何一步步把损失变小，学习率过大或过小会怎样
- 说明决策树如何用信息增益或基尼系数选择划分特征，集成学习为什么能“三个臭皮匠顶个诸葛亮”
- 解释偏差与方差、过拟合与欠拟合的含义以及正则化的作用
- 说明卷积和池化在图像中提取了什么，循环神经网络为什么能处理序列
- 解释支持度、置信度、提升度的含义以及“提升度小于 1”说明什么

### 应用（Apply）

- 使用 pandas 和 scikit-learn 完成缺失值处理、编码、标准化和特征构造
- 使用 scikit-learn 训练并评估回归、分类、聚类模型
- 使用交叉验证和网格搜索为模型选择超参数，使用 Pipeline 防止数据泄露
- 使用 XGBoost 或 LightGBM 完成表格数据的分类和回归任务
- 使用 PyTorch 或 Keras 搭建并训练一个简单的全连接网络、卷积网络和 LSTM
- 使用 joblib 保存模型，并用 FastAPI 或 Gradio 把模型做成可调用的接口

### 分析（Analyze）

- 分析一个业务问题，判断它属于回归、分类、聚类还是关联分析
- 通过探索性分析发现数据中的缺失、异常、不平衡和泄露问题
- 通过混淆矩阵、学习曲线和错误案例分析模型出错的原因
- 通过特征重要性和 SHAP 值分析哪些因素影响了模型的预测
- 比较不同算法在同一数据集上的效果、速度和可解释性

### 评价（Evaluate）

- 根据业务目标（例如漏判代价更高还是误判代价更高）选择合适的评价指标和分类阈值
- 判断一个模型是否过拟合，并给出改进措施
- 评估一条关联规则是否有业务价值
- 评估一个模型在公平性、可解释性和数据合规方面的风险

### 创造（Create）

- 为一个业务场景设计完整的机器学习方案，包括数据清洗规范、特征方案和评价方案
- 撰写规范的模型测试报告，包含指标、错误案例分析和改进建议
- 综合项目：选择一个真实场景（如客户流失预警、二手房价格预测、门店销量预测），完成从数据处理、建模、调参到部署成接口的全过程，并提交项目报告
