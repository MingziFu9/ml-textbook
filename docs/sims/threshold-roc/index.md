## 教学说明

**学习目标**

1. 能根据混淆矩阵计算准确率、精确率、召回率、F1 值和假阳性率（应用）；
2. 能解释阈值变化时精确率和召回率为什么此消彼长，ROC 曲线和 PR 曲线上的每个点代表什么（理解）；
3. 能根据漏诊、误诊的代价为一个具体场景选择阈值（评价）。

**画面与操作**

- 左上是测试集 171 例的恶性概率直方图，红色是实际恶性、绿色是实际良性，蓝色竖线是阈值。直接在图上拖动或拖动下方滑块，都能改变阈值（0.01～0.99）。
- 右上是混淆矩阵（以恶性为正类）和五个指标。
- 下方是 ROC 曲线和 PR 曲线，红点是当前阈值对应的位置；右下角显示 AUC 和 AP。
- 三个场景按钮：默认 0.5、初筛 0.3（尽量不漏诊）、0.8（不想误诊）。

**数据来源**：实验 4-2（`labs/ch04/lab4_2_threshold_roc.py`）中只用 5 个特征的逻辑回归在测试集上输出的概率，由脚本导出为 `lab4_2_scores.json` 后嵌入页面。阈值 0.1～0.9 的混淆矩阵与实验输出的表格一致，AUC = 0.980、AP = 0.972 也与实验一致。

**课堂用法建议**

1. 先让学生把阈值放在 0.5，口算精确率和召回率，再看页面核对。
2. 让学生从 0.9 慢慢拖到 0.1，记录漏诊和误诊的例数，体会“此消彼长”；同时观察红点沿 ROC 曲线从左下走到右上。
3. 分组讨论：如果这是社区乳腺癌初筛，阈值定多少？如果是决定是否手术，又该定多少？要求说出理由。
4. 提问：阈值改变时，AUC 为什么不变？（AUC 评价的是整条曲线，即模型把恶性排在良性前面的能力，与阈值无关。）
