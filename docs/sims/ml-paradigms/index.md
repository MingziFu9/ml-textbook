## 教学说明

**学习目标**

1. 能根据训练数据有没有标签、标签是数值还是类别、是否靠奖励试错，判断一个场景属于哪种学习范式（应用）；
2. 能说出“预测销量是回归”“客户分群是聚类”这类常见易错判断的理由（理解）。

**画面与操作**

- 12 张场景卡片，每张下面有“监督学习·分类”“监督学习·回归”“无监督学习”“强化学习”四个按钮。
- 点一个按钮，卡片变绿（对）或变红（错），并显示理由；可以改选。
- 上方显示答对数量，下方汇总你在每一类中选了几个、正确答案各有几个。“重做”清空全部选择。

**数据来源**：12 个场景由编者根据教材 1.1.2、1.3 节的例子整理，正确答案为分类 4 个、回归 3 个、无监督学习 3 个、强化学习 2 个。

**课堂用法建议**

1. 讲完 1.3 节后让学生用手机扫码独立完成，限时 3 分钟，统计全班最常错的场景。
2. 重点讨论“预测门店销量”（容易误判为分类）和“会员分群”（容易误判为分类）两题，强调“看标签，不看特征”。
3. 请学生再举一个自己工作中的例子，说出它属于哪种范式、标签是什么。
