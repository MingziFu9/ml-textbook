## 教学说明

**学习目标**

1. 能根据 eps 和 min_samples 判断一个点是核心点、边界点还是噪声点（应用）；
2. 能说明 eps 过大、过小对聚类结果的影响（分析）。

**画面与操作**

- 大圆点是核心点，小圆点是边界点，颜色表示所属的簇；灰色叉是噪声点。
- 拖动 eps（0.05～1.0）和 min_samples（2～15），下方显示簇的个数、核心点、边界点和噪声点的数量。
- 点击任意一个点，画出以它为圆心、eps 为半径的圆，并说明它为什么是核心点、边界点或噪声点。
- 可切换月牙形、密度不同、球形三组数据。

**数据来源**：实验 8-2 第一部分的三组二维数据（已标准化）。编者核对：min_samples = 5 时，月牙形数据 eps = 0.1、0.2、0.3 分别得到 21 簇 / 160 个噪声点、3 簇 / 5 个、2 簇 / 0 个；密度不同的数据 eps = 0.3 得到 3 簇 / 16 个噪声点；min_samples = 10、eps = 0.2 时月牙形得到 8 簇 / 70 个噪声点，均与 scikit-learn 的 `DBSCAN` 一致。

**课堂用法建议**

1. 先在月牙形数据上把 eps 从 0.1 拖到 1.0，让学生记录簇数和噪声点数，找出能正确分开两个月牙的 eps 范围。
2. 固定 eps = 0.2，把 min_samples 从 5 调到 10，观察核心点变少、噪声点变多。
3. 切到“密度不同”，讨论为什么同一个 eps 很难同时适合疏密不同的簇。
