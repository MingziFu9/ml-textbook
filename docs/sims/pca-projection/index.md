## 教学说明

**学习目标**

1. 能说出第一主成分是投影后方差最大的方向（记忆）；
2. 能解释方差解释率的含义，以及两个特征高度相关时为什么一个主成分就够了（理解）。

**画面与操作**

- 蓝点是 300 位客户，横轴是 ln(1 + 购买次数)，纵轴是 ln(1 + 消费金额)，两个方向比例相同；黑色十字是均值点。
- 红色直线是投影方向，红色细线是每个点到直线的垂直投影；下方长条是投影后的一维数据。
- 拖动角度（0°～179°），下方显示投影后的方差、保留的方差比例和丢掉的方差比例；点“找方差最大的方向”，直线自动转到第一主成分。

**数据来源**：实验 8-1 订单数据中前 300 位客户的购买次数 F 和消费金额 M，取 log(1 + x)，未标准化。编者核对：scikit-learn 的 `PCA` 给出第一主成分方向约 64.3°，方差解释率 98.5%，与页面一致；0° 时保留 19.7%，45° 时保留 87.9%。

**课堂用法建议**

1. 先让学生猜哪个角度保留的信息最多，再拖动验证，注意观察长条上的点分得开不开。
2. 转到与第一主成分垂直的方向（约 154°），看保留比例只剩约 1.5%，说明这就是第二主成分。
3. 讨论：保留的比例 + 丢掉的比例为什么总是 100%？投影线总长度最短和方差最大为什么是同一个方向？
