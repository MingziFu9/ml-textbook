## 教学说明

**学习目标**

1. 能说出 Q 表中每个数的含义，能把一步经历代入 Q 学习更新公式算出新的 Q 值（应用）；
2. 能根据实验现象说明学习率、折扣因子、探索率对学习过程的影响（分析）。

**画面与操作**

- 左边是与实验 12-3 相同的 4 × 4 冰湖（不打滑）：S 起点，H 冰窟窿，G 终点，橙色圆点是智能体。每个格子四边的小数字是该格“往左、往下、往右、往上”四个动作的 Q 值，中间的箭头是 Q 值最大的动作，格子越蓝表示最大 Q 值越大。
- 拖动学习率 α、折扣因子 γ、探索率 ε。按“走一步”，右上方显示这一步是探索还是利用、到了哪一格，以及更新公式代入数字的全过程；“跑完一回合”“跑 100 回合”连续训练；“清空 Q 表”从头开始。
- 右下方是训练记录：完成的回合数、到达终点的次数、最近 20 回合的成功率曲线，以及起点四个动作的 Q 值。

**数据来源**：冰湖地图与 Gymnasium 的 FrozenLake-v1（4 × 4，不打滑）相同；奖励设置也相同，只有走到终点得 1 分。随机数用固定种子，清空 Q 表后结果可以重现。编者核对：取默认参数（α = 0.5，γ = 0.95，ε = 0.3）连续训练 2000 回合后，每格最大 Q 值都等于理论最优值，起点为 0.95⁵ = 0.774，终点左边一格为 1.000，与实验 12-3 的结果一致。

**课堂用法建议**

1. 清空 Q 表后连按“走一步”，让学生说出为什么前面很多步 Q 值都不变（奖励只有终点才有，要先碰巧走到终点）。
2. 第一次走到终点后，再跑几回合，观察数值怎样从终点附近一格一格“倒着”传回起点，每传一格乘一次 γ。
3. 把 ε 调到 0 后清空重跑，再调到 1 重跑，比较成功率曲线，讨论探索与利用的平衡；把 γ 调到 0.5，看起点的 Q 值变成多少，说明折扣因子的含义。
