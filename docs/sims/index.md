# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [三种学习范式分一分](ml-paradigms/index.md) | 给 12 个真实场景判断属于分类、回归、无监督学习还是强化学习，马上看到对错和理由 |
| 第 2 章 | [预处理流水线](preprocess-pipeline/index.md) | 用 8 行二手房原始数据，一步步打开去重、去单位、修正错误、统一写法、填充、删泄露字段、独热编码和标准化，看数据表怎样变化 |
| 第 3 章 | [梯度下降下山](gradient-descent/index.md) | 在 5 套房子的损失“地形图”上，选择学习率、选择面积是否标准化，一步步看梯度下降怎样走到损失最低点 |
| 第 3 章 | [多项式阶数与过拟合](poly-overfit/index.md) | 用 20 天的奶茶销量数据，拖动多项式阶数和岭回归强度，看拟合曲线、训练误差和测试误差怎样变化 |
| 第 4 章 | [阈值、混淆矩阵与 ROC](threshold-roc/index.md) | 用实验 4-2 中逻辑回归对 171 例乳腺肿瘤给出的恶性概率，拖动分类阈值，看混淆矩阵、精确率、召回率以及 ROC、PR 曲线上的点怎样同步变化 |
| 第 5 章 | [Bagging 与 Boosting](bagging-boosting/index.md) | 在一组一维回归数据上，一棵一棵地添加回归树，对比梯度提升的逐步纠错和随机森林式的平均 |
| 第 5 章 | [决策树生长](decision-tree-split/index.md) | 用 15 条贷款申请数据，自己选择每个节点的划分特征，实时查看信息增益、信息增益率和基尼系数 |
| 第 6 章 | [SVM 间隔与核函数](svm-margin/index.md) | 调惩罚参数 C 和 RBF 核的 gamma，拖动、添加、删除数据点，看决策边界、间隔和支持向量怎样变化 |
| 第 7 章 | [关联规则计算器](assoc-rules/index.md) | 在 10 张超市小票上选出规则的前件和后件，自动算出支持度、置信度和提升度，并标出参与计算的小票 |
| 第 7 章 | [KNN 决策区域](knn-regions/index.md) | 在葡萄酒数据的两个特征上改 K 值、换距离、开关标准化，看 K 近邻的分类区域怎样变化，点击任意位置查看它的 K 个邻居和投票 |
