## 教学说明

**学习目标**

1. 能按定义计算一条关联规则的支持度、置信度和提升度（应用）；
2. 能根据提升度判断规则是否有价值，说明置信度高的规则为什么不一定有用（评价）。

**画面与操作**

- 表格列出 10 张小票。在“如果买了”一行选前件（可以多选），在“那么也买”一行选后件。
- 含前件的小票标蓝色，前件、后件都含的小票标绿色；下方显示三个指标和算式。
- “试一试”按钮给出几条典型规则：面包 → 牛奶与牛奶 → 面包（置信度不同、提升度相同），啤酒 → 花生与花生 → 啤酒，提升度小于 1 的啤酒 → 面包，前件含两件商品的规则。

**数据来源**：教材 7.4.2 节“算一算”中的 10 张小票（编者构造）。

**课堂用法建议**

1. 先让学生手算“面包 → 牛奶”的三个指标，再用页面核对。
2. 对比“面包 → 牛奶”和“牛奶 → 面包”：为什么支持度、提升度一样，置信度可能不同？
3. 讨论“啤酒 → 面包”的提升度 0.40 说明什么，门店应该把这两样东西放在一起吗？
