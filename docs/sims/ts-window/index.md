## 教学说明

**学习目标**

1. 能说出滑动窗口怎样把时间序列变成监督学习的训练样本，什么是滞后特征（理解）；
2. 能比较不同窗口长度和方法的预测误差，说明窗口要覆盖季节周期（分析）。

**画面与操作**

- 上方是社区超市最后 112 天的每日销量，橙点是促销日；前 84 天用来训练，灰色底的最后 28 天用来检验，红线是所选方法的预测。
- 拖动窗口长度 W（1～28）；按“窗口向右滑一格”，蓝框是窗口里的 W 天（特征），橙条是下一天（答案），下方表格逐行切出训练样本。选择红线画哪种方法：窗口平均、上周同一天、线性回归（窗口里的 W 个数作特征）。右下表是三种方法在最后 28 天的 MAE、MAPE。

**数据来源**：实验 12-1、12-2 使用的 `labs/data/store_sales.csv`（教材编写的模拟数据）的最后 112 天。这里是逐日预测（每天用到前一天为止的真实数据预测第二天），比实验中一次预测未来 28 天容易，误差不能直接与实验比较。编者核对：W = 3、7、14、28 时三种方法的 MAE、MAPE 与 Python（scikit-learn 线性回归）计算结果完全一致，例如 W = 7 时分别为 416.0、232.5、239.1 件。

**课堂用法建议**

1. W = 3 时滑几格，让学生说出每一行的特征和答案各是哪几天；再看线性回归误差为什么很大。
2. 把 W 调到 7，看线性回归的系数最大的是哪两天，联系“星期效应”。
3. 让学生预测 W = 28 时线性回归会变好还是变差，再拖动验证，讨论样本数和特征数的关系。
