## 教学说明

**学习目标**

1. 能指出决策边界、间隔边界和支持向量，说明为什么只有支持向量决定边界（理解）；
2. 能说明惩罚参数 C 和 RBF 核参数 gamma 变大、变小时边界的变化，判断欠拟合和过拟合（分析）。

**画面与操作**

- 四组预设数据：实验 6-1 的二维数据、实验 6-1 第③步加了一个异常点的数据（黄框标出异常点）、实验 6-2 的月牙形和同心圆数据（标准化后的训练集）。
- 选线性核或 RBF 核，拖动 C（0.01～1000）和 gamma（0.1～100）。实线是决策边界，两条虚线是间隔边界，绿圈是支持向量，底色表示模型把这片区域判为哪一类。
- 拖动一个点可以移动它；在空白处点击，按“点击添加”的选择加一个红点或蓝点；双击一个点删除它。
- 下方显示支持向量数、训练准确率、间隔宽度（只对线性核有意义）和训练集分错的点数。

**数据来源**：四组数据由 `labs/ch06/lab6_1_linear_svm.py` 和 `lab6_2_kernels.py` 的同一套代码生成。页面用与 scikit-learn 相同的 SMO 算法（libsvm 的工作集选择和停止容差 0.001）在浏览器中求解，编者逐一核对：实验 6-1 数据上 C = 0.01、0.1、1、100 时支持向量 44、18、8、6 个，间隔 4.04、2.05、1.34、0.68；加异常点后 C = 1000 时间隔 0.40，C = 0.1 时 2.91；月牙数据 C = 1、gamma = 0.1、1、10、100 时训练准确率 0.871、0.957、0.981、1.000，与实验输出完全一致。

**课堂用法建议**

1. 在“实验 6-1 数据”上，先让学生找出哪些点是支持向量，再拖动一个远离边界的点，看边界动不动；然后拖动一个绿圈的点，看边界怎样跟着变。
2. 切到“加一个异常点”，C 取 1000 和 0.1 各看一次，讨论：哪条边界更可信？业务中出现录入错误、个别特殊客户时，C 应该大还是小？
3. 在“同心圆”上先用线性核（准确率只有一半左右），再换 RBF 核；在“月牙形”上把 gamma 从 0.1 拖到 100，让学生说出哪一档是欠拟合、哪一档是过拟合，并和实验 6-2 第③步的交叉验证表对照。
