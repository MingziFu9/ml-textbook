## 教学说明

**学习目标**

1. 能说出隐藏层、学习率、激活函数对训练的影响（理解）；
2. 能根据损失曲线判断学习率过大或过小（应用）。

**画面与操作**

- 左图底色是网络对每一点输出“1”的概率，黑线是 0.5 的分界线，四个圆点是异或数据；右图是损失随轮数的变化（对数横轴）。
- 拖动隐藏神经元个数（1～8），选择学习率（0.01～30）和激活函数（Sigmoid、tanh、ReLU）；按“训练 1 轮 / 100 轮 / 1000 轮”，下方显示四个点的输出和提示。改设置会重新开始。

**数据来源**：异或的四个点。初始权重与实验 10-1 用 NumPy 随机种子 0 生成的相同；编者核对：H = 4、学习率 1、Sigmoid 时，第 1、100、500、1000 轮的损失为 0.7441、0.6904、0.1105、0.0198，与实验输出一致。

**课堂用法建议**

1. 先用默认设置训练 100 轮、再训练 1000 轮，看分界线从直线变成弯的；对照实验 10-1 的输出。
2. 把隐藏神经元调成 1，训练 1000 轮，讨论为什么学不会。
3. 把学习率分别调成 0.01 和 30，观察损失曲线，说出“太小”和“太大”各是什么样子。
