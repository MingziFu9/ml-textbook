## 课程与学习方法 { #faq-1 }

??? question "数学基础不好，能学会这门课吗？"

    能。本书每个算法先讲它解决什么问题、直观上怎么想，公式只保留最必要的，并配有可以用纸笔完成的“算一算”。会四则运算、知道平均数和比例，就能跟上大部分内容；遇到求导、矩阵乘法的地方，书中都给出了算好的小例子。最重要的是动手把实验跑一遍，看数字怎么变。

??? question "这门课和“人工智能导论”“自然语言处理导论”等课是什么关系？"

    “人工智能导论”讲人工智能的全貌、发展史和伦理总框架，本课专讲机器学习的算法与项目流程，是后续深度学习、自然语言处理、计算机视觉等课的基础。重叠的知识点只在一门课里细讲，其他课简要介绍并给出链接，例如 RLHF 详见《自然语言处理导论》第 9 章，见 [12.6.4 节](../chapters/12-timeseries-rl/index.md#1264)。

??? question "每章三个实验都要做吗？"

    标 ★ 的基础实验建议都做，标 ☆ 的拓展实验可以课后选做。实验学时少于 3 学时的章，教师会指定其中两个。每个实验末尾的“实验记录表”和“实验报告要求”就是要交的作业。课时安排见[附录 C](../appendix/c-environment.md)。

??? question "怎样用好在线练习和交互动画？"

    每章的单选、多选、判断题可以在网页上直接点击作答，答错了点“回看”链接跳回正文。交互动画嵌在正文中，也可以从[交互动画](../sims/index.md)页单独打开，建议先按动画下方的提示操作，再预测“改了这个参数会怎样”，最后动手验证。

??? question "怎样准备期末考试和职业技能证书考试？"

    期末为闭卷考试，具体题型以学校通知为准；课后练习的单选、多选、判断、简答、实操五种题型与证书理论考试的题型一致，可以当作练习。每章的“本章小结”和概念清单是复习提纲，正文中紫色的“证书考点”提示框标出了四个证书的常考内容，对照见[证书考点对照](../certificate.md)；[学习图谱](../learning-graph/index.md)可以帮你理清概念之间的先后关系。

## 基本概念 { #faq-2 }

??? question "机器学习、深度学习、人工智能是什么关系？"

    一层套一层：人工智能是让机器表现出智能的技术总称，机器学习是实现人工智能的一类方法（从数据中学规律），深度学习是机器学习中使用多层神经网络的一个分支。见 [1.1.3 节](../chapters/01-intro/index.md#113)。

??? question "监督学习、无监督学习、强化学习怎么区分？"

    看有没有“标准答案”：监督学习有标签（如房价、是否流失），做回归或分类；无监督学习没有标签，找数据自身的结构，如聚类、降维；强化学习既没有标签也没有现成数据，智能体通过与环境互动、根据奖励试错学习。见 [1.3 节](../chapters/01-intro/index.md#13) 和 [12.5.1 节](../chapters/12-timeseries-rl/index.md#1251)。

??? question "模型的“参数”和“超参数”有什么区别？"

    参数是模型从数据中学出来的，如线性回归的权重、神经网络的连接权重；超参数是训练前由人设定的，如决策树的最大深度、学习率、K 近邻的 K。调参指的是调超参数。见 [9.3.1 节](../chapters/09-model-tuning/index.md#931)。

??? question "训练集、验证集、测试集各有什么用？"

    训练集用来学参数；验证集用来比较模型、选超参数、决定何时早停；测试集只在最后用一次，估计模型上线后的真实效果。用测试集挑模型，测试成绩就会偏乐观。见 [9.2.4 节](../chapters/09-model-tuning/index.md#924)。

??? question "什么是过拟合？怎样判断和处理？"

    过拟合是模型把训练数据中的偶然波动也当成规律记住了，训练成绩很好、新数据上很差。判断方法是比较训练集和验证集的成绩，或画学习曲线。处理办法有：增加数据、简化模型、正则化、剪枝、Dropout、早停等。见 [3.5.2 节](../chapters/03-linear-regression/index.md#352) 和 [9.1.2 节](../chapters/09-model-tuning/index.md#912)。

??? question "准确率很高，为什么模型还可能没用？"

    类别不平衡时，准确率会骗人：欺诈交易只占 1% 左右，模型把所有交易都判成“正常”，准确率也有 99%，却一笔欺诈也抓不到。这时要看精确率、召回率、F1、PR 曲线。见 [4.5.1 节](../chapters/04-logistic-regression/index.md#451)。

??? question "精确率和召回率哪个更重要？"

    看业务代价。漏判代价高（如癌症筛查、欺诈识别）时更看重召回率，可以把阈值调低；误判代价高（如把正常邮件当垃圾邮件删掉）时更看重精确率。两者此消彼长，用阈值来权衡。见 [4.4.1 节](../chapters/04-logistic-regression/index.md#441)。

??? question "什么是数据泄露？为什么它危害很大？"

    数据泄露是训练时用到了预测时拿不到的信息，比如用全部数据算标准化的均值、用“是否已退款”预测“是否会退货”、时间序列中用了未来的数据。它让离线成绩虚高，上线后效果大跌。办法是先划分再预处理，用 Pipeline 把预处理放进交叉验证。见 [2.5 节](../chapters/02-preprocessing/index.md#25) 和 [9.4 节](../chapters/09-model-tuning/index.md#94)。

## 算法与模型选择 { #faq-3 }

??? question "这么多算法，拿到一个问题先用哪个？"

    先确定任务类型（回归、分类、聚类……），再按“先简单、后复杂”的顺序试：先做一个简单基准（如逻辑回归、线性回归、季节朴素），表格数据再试随机森林、LightGBM 这类树模型，往往效果最好；图片、文本、语音等非结构化数据才考虑神经网络。用交叉验证比较，选效果够好、又容易解释和维护的。

??? question "哪些算法需要做特征缩放？"

    依赖距离或梯度的算法需要：K 近邻、SVM、K 均值、PCA、逻辑回归和线性回归（用梯度下降或正则化时）、神经网络。决策树、随机森林、梯度提升树按阈值划分，不需要缩放。见 [2.3.4 节](../chapters/02-preprocessing/index.md#234)。

??? question "线性回归为什么也叫“最小二乘”？梯度下降又是做什么的？"

    线性回归要找一条直线，使所有样本误差的平方和最小，所以叫最小二乘。这个最优解可以直接用公式算，也可以用梯度下降一步步逼近：每次沿着损失下降最快的方向走一小步。梯度下降是神经网络训练的基础。见 [3.2.3 节](../chapters/03-linear-regression/index.md#323) 和 [3.3 节](../chapters/03-linear-regression/index.md#33)。

??? question "逻辑回归名字里有“回归”，为什么是分类算法？"

    它先像线性回归那样算一个加权和，再用 Sigmoid 函数把结果压到 0～1 之间，当作属于正类的概率，最后按阈值分类。名字是历史原因留下的。见 [4.2.1 节](../chapters/04-logistic-regression/index.md#421-sigmoid)。

??? question "随机森林和梯度提升树有什么不同？"

    两者都由很多决策树组成。随机森林并行训练很多棵树，各自独立，最后投票或平均，主要降低方差；梯度提升树一棵接一棵地训练，每棵树纠正前面的错误，主要降低偏差，效果通常更好但更需要调参。XGBoost、LightGBM 是梯度提升树的高效实现。见 [5.4.2 节](../chapters/05-decision-tree/index.md#542-bagging-boosting)。

??? question "SVM 的 C 和 gamma 怎么调？"

    C 越大，越不允许样本越界，间隔越窄，容易过拟合；gamma 越大，每个样本的影响范围越小，边界越弯曲，也容易过拟合。一般先标准化，再用网格搜索在对数刻度上一起调（如 0.01、0.1、1、10、100）。见 [6.3.4 节](../chapters/06-svm/index.md#634-gamma-c)。

??? question "朴素贝叶斯的“朴素”是什么意思？"

    假设在类别已知时各个特征相互独立。现实中词与词并不独立，但这个假设让计算非常简单，在垃圾短信、文本分类上效果往往不错。见 [7.3.1 节](../chapters/07-knn-bayes-rules/index.md#731)。

??? question "K 均值的 K 怎么定？"

    可以画肘部法则曲线（误差平方和随 K 的变化，找拐点），或比较轮廓系数（越接近 1 越好），但最终还要看业务上能不能解释、用不用得上，例如营销部门能不能为每一群客户设计不同的方案。见 [8.1.4 节](../chapters/08-clustering/index.md#814-k)。

??? question "PCA 和 t-SNE 都能降维，有什么区别？"

    PCA 是线性变换，降维后的数据可以继续用于建模，还能看每个主成分保留了多少方差；t-SNE 是非线性方法，适合把高维数据画成二维图看聚团情况，但结果只用来看图，不能用于新数据，也不宜用于建模。见 [8.3.4 节](../chapters/08-clustering/index.md#834-t-sne)。

## 评估、调参与部署 { #faq-4 }

??? question "交叉验证要做几折？"

    常用 5 折或 10 折。数据少时折数多一些，数据多或模型慢时 3～5 折就够了。分类问题用分层 K 折保持各折类别比例一致；有时间先后的数据必须用时间序列交叉验证。见 [9.2.2 节](../chapters/09-model-tuning/index.md#922-k-k)。

??? question "网格搜索、随机搜索和 Optuna 怎么选？"

    超参数少、取值少时用网格搜索；超参数多时用随机搜索或 Optuna，同样的试验次数通常能找到更好的组合。调参的收益往往有限，先把数据和特征做好更重要。见 [9.3 节](../chapters/09-model-tuning/index.md#93)。

??? question "模型训练好了，怎样让别人用起来？"

    用 joblib 把整条流水线（预处理 + 模型）保存成文件，再用 FastAPI 做成预测接口供其他系统调用，或者用 Gradio 做成网页小工具。上线后还要监控输入数据是否漂移、效果是否下降。见 [9.6 节](../chapters/09-model-tuning/index.md#96)。

??? question "SHAP 值和特征重要性有什么不同？"

    特征重要性说的是“整体上哪些特征重要”；SHAP 值能解释**某一个样本**的预测：模型输出 = 基准值 + 每个特征的贡献，正的往上推、负的往下拉。业务人员问“为什么判这位客户高风险”时用 SHAP。见 [9.5.2 节](../chapters/09-model-tuning/index.md#952-shap)。

## 神经网络与深度学习 { #faq-5 }

??? question "为什么要用激活函数？不用会怎样？"

    没有激活函数，多层神经网络叠起来仍然只是一个线性变换，和一层没有区别，学不会异或这样的非线性问题。ReLU 计算简单、不容易梯度消失，是隐藏层最常用的激活函数。见 [10.2.2 节](../chapters/10-neural-network/index.md#1022)。

??? question "PyTorch 和 Keras 学哪个？"

    两个都值得了解。Keras 写法简洁，几行就能搭网络、训练，适合入门和快速试验；PyTorch 要自己写训练循环，更灵活，是研究和大模型领域的主流。本书第 10、11 章同一个任务都给了两份代码，Keras 3 用 PyTorch 作后端。见 [10.5.3 节](../chapters/10-neural-network/index.md#1053)。

??? question "没有显卡能学深度学习吗？"

    能。本书第 10～12 章的实验都在 CPU 上完成，每个用时不超过 1 分钟左右，例如实验 11-2 的卷积网络训练 10 轮约 24 秒。更大的网络可以用云算力平台或学校的 GPU 服务器。见[附录 C](../appendix/c-environment.md)。

??? question "训练时损失不下降或变成 nan，怎么办？"

    依次检查：输入有没有标准化；学习率是否太大（先降到原来的十分之一试试）；标签格式和损失函数是否匹配（多分类用整数标签配 `CrossEntropyLoss`）；每一批是否调用了 `zero_grad()`；数据里是否有 nan。见 [10.4.2 节](../chapters/10-neural-network/index.md#1042)。

??? question "卷积神经网络为什么比全连接网络更适合图片？"

    卷积层局部连接、参数共享：每个输出只看一小块区域，同一个卷积核在整张图上共用。参数少、能抓住边缘纹理等局部图案，图片稍微平移也能识别。实验 11-2 中同样约 10 万个参数，CNN 测试准确率 0.877，多层感知机 0.847。见 [11.2.4 节](../chapters/11-cnn-rnn/index.md#1124)。

??? question "LSTM 一定比简单方法好吗？"

    不一定。实验 11-3 的短信分类中 LSTM 只比朴素贝叶斯略好、慢得多；实验 12-2 的销量预测中 LSTM 不如霍尔特—温特斯和 LightGBM。数据少、规律简单时，经典方法常常更好。见 [11.6 节](../chapters/11-cnn-rnn/index.md#116) 和 [12.4.1 节](../chapters/12-timeseries-rl/index.md#1241)。

## 时间序列与强化学习 { #faq-6 }

??? question "时间序列为什么不能随机划分训练集和测试集？"

    打乱以后，模型会用“未来”的数据去预测“过去”，等于提前看到了答案。实验 12-2 中打乱顺序的 K 折 MAE 为 148.7，按时间顺序的交叉验证为 170.9，打乱后成绩虚高。要按时间切分，用最后一段做测试。见 [12.3.3 节](../chapters/12-timeseries-rl/index.md#1233)。

??? question "预测未来 28 天，为什么不能用“昨天的销量”做特征？"

    因为预测第 28 天时，第 27 天的销量还没发生。特征必须是预测那一刻已经知道的：日期、提前公布的促销和节假日、至少 28 天以前的销量。见 [12.3.1 节](../chapters/12-timeseries-rl/index.md#1231)。

??? question "MAE 和 MAPE 用哪个？"

    MAE 有单位（平均差多少件），直观；MAPE 是百分比，可以比较不同商品、门店，但实际值很小或为 0 时会失真。两者都要和基准方法（如季节朴素）比较才有意义。见 [12.4.2 节](../chapters/12-timeseries-rl/index.md#1242)。

??? question "Q 学习中的 α、γ、ε 分别是什么？"

    α 是学习率，决定每次往目标值挪多少；γ 是折扣因子，决定对远处奖励的重视程度，越接近 1 越有远见；ε 是随机探索的概率，用来平衡探索与利用，一般从大到小逐渐减小。见 [12.6.1 节](../chapters/12-timeseries-rl/index.md#1261)。

??? question "强化学习和大模型有什么关系？"

    大模型训练的最后阶段常用人类反馈强化学习（RLHF）：用人对回答的偏好训练奖励模型，再用强化学习调整大模型；推理模型则用“答对给奖励”的强化学习学会一步步思考。见 [12.6.4 节](../chapters/12-timeseries-rl/index.md#1264) 和 [12.8 节](../chapters/12-timeseries-rl/index.md#128)。

## 实验环境与排错 { #faq-7 }

??? question "实验代码报 `ModuleNotFoundError`，怎么办？"

    说明当前 Python 环境里没有装这个库，或者库装在了另一个环境。确认激活了实验用的虚拟环境，再运行 `pip install -r labs/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。注意 `sklearn` 的安装名是 `scikit-learn`，`gymnasium` 不要装成旧的 `gym`。见[附录 C](../appendix/c-environment.md)。

??? question "提示找不到数据文件（`FileNotFoundError`），怎么办？"

    实验代码用相对路径 `../data/` 读数据，要先进入代码所在的目录再运行，例如 `cd labs/ch05` 后运行 `python lab5_2_random_forest.py`。在 Jupyter 中可以用 `os.chdir` 切换目录。

??? question "图中的中文显示成方框，怎么办？"

    电脑上没有代码中列出的中文字体。Windows、macOS 一般自带黑体、微软雅黑或苹方；Linux 安装 `fonts-noto-cjk` 或 `fonts-wqy-zenhei`。设置方法见[附录 A.4](../appendix/a-python.md#a4-matplotlib)。

??? question "我的运行结果和书上的数字不完全一样，是做错了吗？"

    不一定。不同电脑、操作系统和库版本的随机数可能不同，神经网络还受多线程计算顺序影响，数字会有小的差别。只要规律和结论一致（如哪个模型更好、大致的数量级）就没有问题。差别很大时，检查数据文件、随机种子和库版本是否与 `labs/requirements.txt` 一致。

??? question "电脑太旧装不了软件，还能做实验吗？"

    可以用在线 Notebook 平台，如百度飞桨 AI Studio、阿里云天池实验室、魔搭社区 Notebook，浏览器打开就能运行，都有免费的 CPU 环境。把 `labs/` 目录上传上去即可。见[附录 C](../appendix/c-environment.md)。

??? question "实验 11-2 下载 Fashion-MNIST 失败怎么办？"

    网络不稳定时会下载失败。可以从课程资源中拷贝 `fashion-mnist` 文件夹到用户目录下的 `.keras/datasets/`，再运行实验，程序会直接读取本地文件。
